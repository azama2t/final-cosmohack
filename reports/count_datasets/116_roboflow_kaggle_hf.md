## Как скачивается (проверено 26.09)
- **Hugging Face** — без ключа (API `huggingface.co/api/datasets`, `resolve/main/...`, HTTP Range по zip работает).
- **Kaggle** — **без логина работает**: список `GET /api/v1/datasets/list?search=…`, файлы `GET /api/v1/datasets/list/<owner>/<ds>`, скачивание архива `GET /api/v1/datasets/download/<owner>/<ds>` и одного файла `…/download/<owner>/<ds>/<путь, / → %2F>` (302 на подписанный URL GCS, Range поддерживается). Пакет `kaggle`/`kagglehub` не нужен.
- **Roboflow Universe** — страницы и поиск читаются только браузером (curl/WebFetch → 403 Cloudflare); **скачивание только с API-ключом** (бесплатная учётная запись). Ключа нет → ни один набор напрямую не скачан. Обход: зеркала Roboflow на HF/Kaggle (ниже №2, №7, №8 — это экспорты Roboflow).
- **GitHub** — поиск репозиториев без токена упёрся в лимит 10 запросов/мин (IP общий с другими агентами); `gh` не установлен; код-поиск без токена недоступен. Проверено по README и zip через Range.
