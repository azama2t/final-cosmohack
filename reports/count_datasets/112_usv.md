# 112 — камера у воды / с судна / USV / мост и берег (Агент 7, INBOX §17–§18)

Сегмент: FML (реестр; модуль — L109), FloW, SeaClear, вырезки ADIS, речные камеры и ловушки, прочие наборы «камера у воды»; по §18 — граф цитирований (OpenAlex) и поиск Zenodo API.
Образцы — `data/extra/count_ds/<name>/` (вне git). Все числа ниже — посчитаны по скачанным файлам, если не помечено «(по описанию)».
Пригодность: (1) обучение счётчика по фото; (2) шт./км² на масштабе кадра (известна площадь кадра); (3) мост к S2.

## Граф цитирований и поиск по API (§18, моя часть)
- OpenAlex: цитирующие FloW (152), MARIDA (119), FloatingObjects (29), UAVVaste (147), Lebreton 2018 (1 844), van Lieshout 2020 (169), IWHR (18), SeaClear (33); 50 работ с «dataset/benchmark/count» в заголовке → `data/extra/count_ds/_tmp/cit/citing_kw.tsv`. Из них дали наборы: IWHR (строка 1), TUD-GV (2), PoTATO (11), SeaClear (отклонён); прочие — морские датасеты навигации (LaRS, WaterScenes, PoLaRIS, MOANA), сортировка отходов (ZeroWaste, SpectralWaste) — не про плавающий мусор.
- Zenodo API (12 запросов, type=dataset): 248 записей → `…/cit/zenodo_hits.tsv`; отсюда RiSID, TUD-HCMC, Groningen, Amsterdam, Oostpoort, CWG-RGB, отрицательные 20413205, 18386827, 15129753. UCWD, TUN-MarineLitter, APLASTIC-Q, Marine Litter (Della Volpe), Batis — сегмент L113 (у них).
- DataCite API (2 запроса, type=dataset, 196 записей) → `…/cit/datacite_hits.txt`: отсюда TOCL RMS, Chao Phraya, Saigon, Banjarmasin; UAV-наборы (AquaPlasticWaste 2026 Mendeley zshjxgfmc3, Drone Saigon 4TU 21648152, riverbanks 4TU 3d24e304) — сегмент L113, переданы строкой в реестр.
- Ещё не проверено: AquaSurf-Malnad-223 (IEEE DataPort 10.21227/k8d4-5n64 — обычно нужна учётная запись), WADE (arXiv 2608.22950: 2 167 кадров, 13 608 рамок — данные «после принятия статьи», пока не открыт), Banjarmasin (Data in Brief 2026, 10.1016/j.dib.2026.113265), USVTrack (закрытая статья), 2510.23798 (геометрическая модель камер у реки).

## Как скачано
Большие zip не тянули целиком: чтение оглавления и выбранных файлов по HTTP Range (`data/extra/count_ds/_tmp/rzip.py`, вне git). Zenodo режет частые запросы (429) — в помощнике пауза и повтор.
