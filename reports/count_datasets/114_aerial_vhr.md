## Отрицательные результаты (проверено — нет открытых изображений с подсчётами)

- **Lebreton 2018 аэромозаики**: в figshare 5873142 только 6 файлов (4 xls, контуры, tif модели); в статье Data availability — «All datasets … on Figshare». Кадры RGB 0.1 м не выложены. Путь — только письменный запрос к The Ocean Cleanup (Lebreton / Sainte-Rose). Шаблон запроса — в разделе ниже.
- **Garaba 2018 SWIR** и **Park 2021 WV-3** — данные по запросу / отсутствуют (см. таблицу).
- **Pléiades / Pléiades Neo**: поиск (Zenodo, OpenAlex, веб) не дал ни одного открытого набора с рамками или подсчётами плавающего мусора; есть только обзорные упоминания и пресс-материалы Airbus.
- **Средиземное море, аэросъёмка наблюдателями** (Zenodo 18387541, 2024, CC BY-NC-SA): это тезисы (PDF 127 КБ): 1.88 ± 2.3 шт./км² по самолёту, 0.89 ± 1.61 с судов; снимков нет — только визуальный учёт.
- **Hawaii Coastal Imagery 2015** (geodata.hawaii.gov ImageServer, 2 см) — сами ортофото открыты (условия State of Hawaii), но точки Moy et al. 2018 (20 658 предметов) как слой не опубликованы; размеченная часть — это набор Winans (п. 1).
- Поиск Zenodo по «WorldView debris», «PlanetScope debris», «floating litter aerial», «Winans debris»: других наборов с рамками для ВР-спутников нет.

### §18: поиск по нишевым каналам (26.09 05:10)
- **DataCite API** (тип dataset; запросы по заголовкам: aerial × litter/debris/plastic; satellite/PlanetScope/WorldView/SkySat/Pléiades × litter/debris × floating/marine; windrow*; airborne × plastic) нашёл в этом сегменте только NASA PS (10.34911/rdnt.9r6ekg), LitterLines (10.5281/zenodo.19571436/7) и Cózar 2024 (уже B). Кроме них — «Airborne spectral reflectance dataset of submerged plastic targets» (Zenodo 7043318): это спектры мишеней, не подсчёты → D. Остальные совпадения — оползни и селевые потоки (USGS), к теме не относятся.
- **NOAA NCEI geoportal** («marine debris aerial imagery»): нашлись только снимки NGS Emergency Response (ураганы, без разметки мусора) и береговые учёты на атолле Мидуэй 2013–2016 (NCEI 0189571, без снимков) → D для нашего сегмента.
- **Zenodo**: заодно найден UCWD (Zenodo 20630252, БПЛА, CC BY 4.0, 12.5 ГБ). Это сегмент L113, в `data/extra/count_ds/ucwd` он уже есть. Здесь не дублируется.

## Что это даёт проекту

- **→ L109 счётчик**: Winans 2023 (10 703 рамки, 2 см, CC BY 4.0) — самый крупный открытый набор «аэрокадр + рамки + известный GSD» в сегменте; домен — берег, для воды нужна проверка переноса. NASA PS (1 640 рамок, 3 м) — счётчик **пятен** на спутниковом снимке ВР, CC BY-NC.
- **→ L115 мост**: NASA PS — 11 сцен с S2 того же дня (|Δt| ≤ 1.5 ч), из них 3 сцены MARIDA; LitterLines — 826 линий окон с продуктом S2 того же дня, все 12 пар тайл+дата совпадают с окнами Cózar 2024 (B у нас). Пиксели Planet для LitterLines в открытом доступе нет (нужен доступ Planet), для NASA PS — есть (RGB 8 бит, visual).
- Физический вывод прежний (L91): отдельные предметы 0.1–5 м видны только на 0.02–0.3 м; на 3 м и 10 м размечаются **скопления** (пятна, окна). Подсчёт «шт./км²» с S2 возможен только через перенос «пятна/окна → предметы» по кадрам ВР, а таких кадров с одновременным S2 и штучным счётом в открытом доступе не найдено.
