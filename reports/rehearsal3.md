- Урок про порог подтвердился: «как есть» при 0.63 даёт 0.256, при пороге из CV (0.999) — 0.389.
- «Как есть» с порогом из CV здесь лучше обученной (0.389 против 0.349). Это не опровергает правило: test собран из val MARIDA, по которому выбирали нашу модель, то есть он для неё «свой». `provenance_check` это и показал (99 % совпадений содержимого). На чужих данных правило «по умолчанию обученная» остаётся верным.
- **CV обученной модели завышен из-за группировки по файлу.** При анонимных именах `group` в манифесте = id файла: 224 группы на 224 файла. Соседние кропы одной сцены попадают в разные фолды. Скрипт при этом печатает «4 folds by scene». По файлам CV 0.4955, при группах по географии (CRS + ячейка 1°, 8 групп; манифест правил вручную: `out\rehearsal3\ingest_grp`) — 0.302; private 0.349. Строка baseline от группировки не зависит (0.457): модель на этих файлах не обучалась. Значит, сравнение «обученная против как есть» на CV по файлам смещено в пользу обученной.
