# Г1-2: интервалы профиля S2 (поле, пластик > 2 см, визуально)

Правило §28 А (docs/PIPELINE.md C10, записано до расчёта): метод интервала — кластерный бутстреп по событиям (кластер = день рейса, 2 000 повторов) и/или NB-GLM (offset ln A); выбор — по покрытию 95 %-интервала на отложенном test (14 событий S2), без подбора на test. Точечные оценки не меняются, только ширина.

Событий 63 (26 дней рейса); dev 44 (19 дн.), отложенный test 14 (5 дн.), буфер 1 сут 5 (не используется). Бутстреп: 2000 повторов по дням рейса.

## 1. Среднее профиля ΣN/ΣA (все события), шт./км²

| интервал 95 % | нижн. | верх. | что учитывает |
|---|---:|---:|---|
| Гарвуд | 49.9 | 58.0 | только ошибка счёта (Пуассон) |
| бутстреп по дням рейса | 39.7 | 70.4 | счёт + разброс между днями |
| NB2 (α = 0.489) | 44.2 | 64.5 | счёт + сверхпуассоновский разброс |

C = 53.9; бутстреп шире Гарвуда в 3.8 раза.

## 2. Среднее dev → среднее отложенного test (один исход, не покрытие)

dev 56.9, test 46.0 [Гарвуд 38.7–54.3]. Гарвуд dev 52.1–62.1: не накрывает; бутстреп 38.8–78.2: накрывает; NB2 44.5–71.8: накрывает.

## 3. Диапазон для одного нового события, 95 %, покрытие 14 событий test

| интервал | диапазон, шт./км² | покрытие test |
|---|---|---:|
| Гарвуд по среднему dev | 52.1–62.1 | 0% |
| прогноз NB2 (площадь полосы события; медиана границ) | 4.3–171.8 | 100% |
| квантили 2.5–97.5 % событий dev | 10.0–160.3 | 93% |
| медиана профиля на карте, 90 % | 9.0–175.2 | 93% |

Номинал 95 %; при n = 14 случайный разброс покрытия ≈ 79%–100%.

## Вывод

Гарвуд — интервал среднего, только ошибка счёта: среднее test (46.0) он не накрывает, отдельные события test — 0% при номинале 95 %. Бутстреп по дням рейса накрывает среднее test (как и NB2). Для одного события оба метода «между событиями» в пределах случайного разброса при n = 14 (NB2 100%, квантили событий dev 93%); ближе к номиналу — квантили событий. Решение: среднее профиля показывать с бутстреп-интервалом по дням рейса (39.7–70.4), Гарвуд — с подписью «только ошибка счёта»; диапазон для одного места — квантили событий (10.0–160.3, покрытие test 93%). Точечные оценки не меняются.
