# Бейзлайны концентрации шт./км² (полевые данные)

**Основной сплит (зафиксирован в configs/case_selection.yaml до моделей): `route_buf1`** — 5 непрерывных участков маршрута по дням рейса (фолд = участок), из train убраны записи ближе 1 сут к test.

Схемы для сравнения: `event` (группа = событие, 5 фолдов), `daycell` (дата × ячейка 1°), `cruiseday` (день рейса = источник × судно × дата), `st` (компоненты R = 100 км, T = 2 сут), `route` (участки без буфера). Метрики по out-of-fold предсказаниям; log1p_mae = mean |log1p(pred) − log1p(true)| (MAPE не используется). ДИ разности MAE — бутстреп по дням рейса (2000 повторов), одинаково для всех схем. «Соседи ±1 сут» — доля kNN-соседей из train, взятых из того же или соседнего дня рейса.

Предикторы: latitude, longitude, wind_speed_kn, sea_state_beaufort (kNN — только координаты; wind_lin — ветер/волнение, только S1). Поля ответа исключены (selection.LEAK_EXPLICIT, assert_no_leak).
