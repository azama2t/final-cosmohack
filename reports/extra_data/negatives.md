## Как получены пиксели (одинаково с сервисом)
- Чтение — тем же кодом, что live-сцены сервиса: `src/macroplastic/live/stac.py::read_crop` (Planetary Computer для дат
  ≥ 2022-01-25 и для 2018 г.; Earth Search исходной обработки для 2021-07-14 — правило `fetch_live.pick_item`), отражательная
  способность = DN·scale + offset из метаданных, 20/60 м → 10 м ближайшим соседом. Признаки — `compute_features(level="win")`
  на окне с полем 360 м, берутся только пиксели ядра.
- Это L2A (Sen2Cor), а MARIDA — ACOLITE rhorc: при дообучении это сдвиг домена (тот же, что у сервиса на live-сценах).
- Суда: 3 ячейки 10.08 км с наибольшим числом рамок на тайл-дату; рамки > 20 000 м² (слипшиеся группы/причалы) отброшены.
  Пиксель рамки — корпус (D), если B8 выше локальной медианы воды (окно 15) на > 0.01; прочие пиксели рамки — вода (C).
- Облака: 36 подсцен open_water без снега с 10–90 % ясно. Маска 1022×1022 px (20 м) — центральная часть контура 1152 px:
  измерено (09UVS: пик корреляции маски с B2 при сдвиге 64 ± 4 px, центр 65). Сцена принимается, если глобальный пик
  корреляции по сдвигам ±40 px лежит в ≤ 6 px от центра и уточнённый r ≥ 0.3: 28 приняты (r 0.39–0.87), 8 отклонены
  (нет L2A в PC — 1; пик не в центре — 5, в т.ч. 01WEM r 0.91 при сдвиге (−9, 3) — возможно, маска там смещена, а не чужая;
  r < 0.3 — 2). Окно 10.08 км — с наибольшей длиной границ облако/ясно; ≤ 3 px от границы — C.

## Формат npz (для `scripts/case/detector_retrain.py prep-extra`)
`X` (N, 48) + `names` (feature_names('win')), `level` по строкам (D / C / W), `klass` (ship, water_ring, cloud,
cloud_shadow, clear_water), `acq` = «тайл_дата», `obj` (рамка / сцена:класс), `y` в кодах MARIDA (5 Ship, 6 Clouds,
13 Cloud Shadows, 7 Marine Water); суда дополнительно `b8_contrast`, `box_id`, `chip`, `chips_meta`; облака — `edge`,
`scene`, `scenes_meta`, `rejected`.

## Воспроизведение
```
set CUDA_VISIBLE_DEVICES=
.venv\Scripts\python.exe scripts\extra_data\l90_vessels_fi.py --cells-per-layer 3 --workers 4
.venv\Scripts\python.exe scripts\extra_data\l90_clouds_cmc.py --workers 3
.venv\Scripts\python.exe scripts\extra_data\l90_clouds_cmc.py --verify-cached
.venv\Scripts\python.exe scripts\extra_data\l90_registry.py
.venv\Scripts\python.exe scripts\extra_data\l90_fp_check.py
```
Входы: `data/extra/finland_vessels/*.gpkg` (Zenodo 15019034), `data/extra/cloudmask_catalogue/{classification_tags.csv,
masks.zip, shapefiles.zip}` (Zenodo 4172871; из masks.zip нужны 36 файлов open_water). Итоги зависят от доступности PC
(обработка 2024 г. для 2022 г.; при переобработке значения пикселей могут слегка измениться).
