# Честность метрики: перепроверка, утечка «того же места», leave-region-out

Модель: `weights/lgbm` (LightGBM, MARIDA train + MADOS, порог 0.63); для сравнения `weights_exp/lgbm/l3_final_backup` (только MARIDA, порог 0.37).
Test-сплит MARIDA не читался ни одним скриптом (списки только `train_X.txt`, `val_X.txt`). Числа — `reports/l16_metric_audit.json`,
сырьё — `weights_exp/l16/*.json`. Скрипты: `scripts/experiments/l16_{common,recheck,paired,lro,harm_val,summarize}.py`.
Метрики везде: пул всех размеченных пикселей (класс > 0), класс MD = 1 против всех остальных, собственный код (`l16_common.confusion/scores`, `metrics.py` не импортируется).

## 1. Перепроверка подсчёта

Полный прогноз каждого из 328 val-патчей 256×256 (признаки на весь патч → бустер → маска размеченных пикселей), своя матрица ошибок.

| модель | TP | FP | FN | F1 | IoU | P | R | meta.json | совпадение |
|---|---|---|---|---|---|---|---|---|---|
| итоговая (MARIDA+MADOS, 0.63) | 984 | 74 | 91 | 0.9226 | 0.8564 | 0.9301 | 0.9153 | 0.9226 / 0.8564 / 0.9301 / 0.9153 | точное, до 4-го знака |
| backup (только MARIDA, 0.37) | 980 | 104 | 95 | 0.9078 | 0.8312 | 0.9041 | 0.9116 | 0.9078 / 0.8312 / 0.9041 / 0.9116 | точное |

Проверки:
- **Val-патчи = `splits/val_X.txt`**: 328 патчей, 12 сцен, 213 102 размеченных px, 1 075 MD px; кэш `out/l3_cache/val_win.npz` содержит те же пиксели в том же порядке; вероятности по кэшу и по полному прогнозу патча совпадают бит в бит (max |Δp| = 0).
- **NaN**: 0 размеченных val-пикселей с NaN хотя бы в одном канале → правило «p := 0 при NaN» на метрику не влияет.
- **Пересечение train/val MARIDA**: 0 общих патчей, 0 общих сцен (36 сцен train и 12 сцен val). Общие тайлы: 16PCC, 16PDC, 16PEC, 18QYF, 48PZC. В двух сценах val та же дата есть в train (S2_12-1-17_16PEC ↔ S2_12-1-17_16PCC; S2_18-9-20_16PCC ↔ S2_18-9-20_16PDC). Со съёмкой того же дня пересекаются по bbox только **2 val-патча** (18-09-20), и в них **0 MD px**: на метрику MD это не влияет.
- **MADOS**: все 16 сцен MADOS, связанных с val MARIDA по `reports/mados_overlap.csv` (та же съёмка или то же место в другую дату), исключены из обучения (список в meta.json совпадает с таблицей). Сцены из test-сплита MADOS в обучение не попали (0). Сцены MADOS, совпадающие по съёмке с test MARIDA (15 шт. по `mados_overlap_with_marida_test.csv`), в обучении не используются (0).
- **Порог выбран на val**: 0.63 = argmax F1 по сетке 0.02…0.98 на val (кривая плоская: 0.63 → 0.9226, 0.70 → 0.9225, 0.50 → 0.9206). Оптимизм выбора порога на тех же данных (выбор на половине сцен val, оценка на другой половине, 200 разбиений): **+0.0065** у итоговой, +0.0084 у backup. Честная оценка при пороге, выбранном не на оцениваемых сценах: ≈ **0.916**.
- **Разброс по сценам**: 95 % бутстрэп-интервал F1 по сценам val (12 сцен, 2000 повторов) — **[0.877; 0.970]**. Указанный в отчётах «± 0.0005» — это только разброс по seed, не неопределённость метрики.
- **Прирост от MADOS значим**: парный бутстрэп по сценам: итоговая − backup = **+0.015 [+0.007; +0.038]**, P(Δ ≤ 0) = 0. MADOS не ухудшил ни одну сцену с ≥ 20 MD px.
- **Оконные признаки и края патча**: признаки считаются на каждом патче 256×256 отдельно (`mode="reflect"`, локальная медиана с отражением) — одинаково для train и val, заглядывания в соседние патчи нет. Но распределение разное: в полосе 15 px у края патча лежит **31 % MD val против 21 % MD train** (доля площади полосы 22 %). На краю F1 = 0.878 (R = 0.816), внутри 0.941 (R = 0.960). Это не утечка, а небольшой пессимизм val относительно инференса по целому снимку (там блоки с перекрытием 32 px, настоящих краёв патча нет).

## 2. Утечка «того же места»

Для каждого val-патча — пересечение его bbox (WGS84) с bbox всех патчей train: 188 из 328 (57 %) перекрываются с train больше чем на 5 % (186 другой датой, 2 той же съёмкой), 27 касаются краем (≤ 5 %), 113 не пересекаются. Порог модели тот же (0.63 / 0.37), 95 % CI — бутстрэп по сценам.

| подмножество val | MD px | сцен | итоговая F1 [95 % CI] | IoU | backup F1 [95 % CI] |
|---|---|---|---|---|---|
| весь val | 1075 | 12 | 0.923 [0.877; 0.970] | 0.856 | 0.908 [0.853; 0.959] |
| перекрытие с train > 5 % | 845 | 9 | 0.927 [0.873; 0.985] | 0.864 | 0.915 [0.855; 0.978] |
| без перекрытия (включая касание краем ≤ 5 %) | 230 | 11 | 0.906 [0.843; 0.933] | 0.829 | 0.880 [0.772; 0.912] |

| **разница «перекрытие − нет»** | | | **+0.021 [−0.039; +0.113]** | | +0.035 [−0.038; +0.157] |

Вывод: на знакомой территории F1 выше на 0.02–0.035, но при 9–11 сценах разница статистически не отличима от нуля. Сильной утечки «того же места» в val нет. Но и проверка слабая: «новые» патчи val — это всё ещё те же регионы (Гондурас, Гаити), только другие участки.

## 3. Leave-region-out (LRO)

Объединённые MARIDA train+val (test не трогали), регион = группа тайлов (`reports/marida_regions.md`). Регионы с ≥ 50 MD px: Гондурасский залив (1388 MD px), Гаити, Порт-о-Пренс (1172), Джакарта (232), Ислас-де-ла-Баия (121); Дурбан (46) и остальные — ниже порога, они всегда остаются в обучении.
Обучение на остальных регионах по рецепту итоговой модели (binary, 48 признаков `win`, все MD + до 30 000 px на класс и 60 000 воды, pos_weight 3, 400 деревьев) + MADOS train+val без сцен, помеченных NO, и без **всех** сцен MADOS, совпавших по `mados_overlap.csv` с любой сценой выпавшего региона (19 / 13 / 4 / 6 сцен). **Порог** для региона R — argmax F1 на out-of-fold прогнозах **других** выпавших регионов (метки R не используются). 3 seed; оценка — пул всех размеченных px региона.

Гармонизация проходит порог по правилу, но у неё есть цена:

Контекст окон (15/31 px) — главное, что держит перенос на новый регион: без него Гондурас падает до 0.06–0.53.

## Выводы (5 строк)

1. Подсчёт честный: своим кодом по полному прогнозу патчей F1 = 0.9226, IoU = 0.8564 (backup 0.9078) — совпадает с meta.json до 4-го знака. NaN нет, пересечений train/val по патчам и сценам нет, MADOS-сцены val исключены, порог 0.63 взят с val (оптимизм ≈ +0.007).
2. Реальная неопределённость val — бутстрэп по 12 сценам, 95 % CI [0.88; 0.97], а не «± 0.0005» (это только seed). Прирост MADOS значим: +0.015 [+0.007; +0.038].
3. «То же место» даёт +0.02 [−0.04; +0.11]: не значимо, сильной утечки нет.
4. На невидимом регионе (LRO, 4 региона) F1 = 0.854 ± 0.007 против 0.923 in-distribution (−0.07). Разброс по регионам 0.71–0.95. Для нового места честная оценка ≈ 0.85, для мелкого региона — до 0.7.
5. На новом регионе помогают MADOS (+0.10) и оконные признаки (без них −0.12…−0.31). Гармонизация по медиане воды даёт +0.023 на LRO, но −0.025 на знакомых местах: включать как опцию для новых сцен или регионов, не по умолчанию. Аугментация и ансамбли прироста не дают.
