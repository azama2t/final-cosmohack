## Проверено буквально (не менялось)
- `powershell -ExecutionPolicy Bypass -File run.ps1 -Case all -Offline` — маршрут кейса без сети, ~6–7 с (см. `reports/selfcheck/clean_clone_1941.md` для чистого клона: полный цикл клон→карта ≈ 7,5 мин).
- `powershell -ExecutionPolicy Bypass -File run.ps1` — сервис на `http://127.0.0.1:8000`, документация `/docs`.
- Ключи, которые реально существуют в `run.ps1` (`param(...)`): `-Port <int>` (по умолчанию 8000), `-DataRoot <string>` (по умолчанию `service\demo` — **в README сейчас не описан**, можно добавить строку «данные сервиса берутся из `-DataRoot` (по умолчанию `service\demo`)»), `-NoBrowser`, `-Cpu`, `-Case prepare|eval|export|all`, `-Offline`, `-Force`. Все, кроме `-DataRoot`, уже в README.
- Абсолютных путей `C:\Users\...` в README нет — ничего чинить не нужно.

Формулировку менять не обязательно, она уже честная.
