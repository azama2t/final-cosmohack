# L3 — пиксельный LightGBM для Marine Debris (MARIDA)

Дата: 25.09.2026, ночь. Всё выбрано **только по val** (официальный сплит MARIDA, 328 патчей, 12 сцен). Test не читался.

## Итоговая модель (weights/lgbm)
- Задача: **бинарная**, MD против всех остальных размеченных классов. Признаки `win` (48 шт.): 11 каналов + 8 индексов + mean/std в окнах 3/7/15 для B8, FDI, NDVI, NDWI + контраст с локальной медианой (B8 и FDI в окнах 15/31, NDVI в окне 31).
- Обучающие пиксели: 186 085 = все MD train (1 943) + до 30 000 на каждый класс 2..15 (для Marine Water до 60 000), выборка с seed. Вес MD 3.0, все conf с весом 1.
- LightGBM: 400 деревьев, 63 листа, lr 0.05, feature/bagging fraction 0.8, seed 0, deterministic. Файл `model.txt` 2.85 МБ. Обучение 4 с на 20 потоках CPU.
- Порог MD подобран по F1 на val: **0.37** (кривая F1 пологая: 0.3 → 0.904, 0.5 → 0.905, 0.7 → 0.901).

## Сдвиг домена: ACOLITE rhorc (MARIDA) → Sen2Cor L2A (живые сцены)
Для двух живых сцен L6 есть сцены MARIDA с той же датой: Дурбан 24.04.2019 (36JUN) и Гаити 03.01.2021 (18QYF). Совпадают только патчи из **train**, из которых по краям пересекаются 21 патч Дурбана: 1.44 млн px, из них 5 449 размечено, 46 MD. Сетки кратны 10 м, пиксели совпадают один в один. Скрипты — `out/l3_logs/domain_shift*.py`.
- Уровень воды (медианы по SCL-воде, rhorc − L2A): Дурбан +0.014 (B1) … +0.007 (B8) … −0.003 (B12); Гаити +0.010 (B1) … +0.0035 (B8). **В Гаити L2A в красном и NIR обрезан до 0.0001** (L6 заменяет отрицательные значения нулём), а в rhorc там 0.004. У слабого мусора сигнал в NIR порядка 0.01, поэтому обрезка стирает часть контраста.
- Та же итоговая модель на тех же 46 MD-пикселях (из train, поэтому абсолютные числа оптимистичны, смотреть надо на изменения):

| вход | MD найдено | FP среди размеченных не-MD | доля помеченных пикселей |
|---|---|---|---|
| rhorc (MARIDA) | 46/46 | 0 | 0.35 ‰ |
| **L2A как есть** | **26/46** | 0 | 0.15 ‰ |
| L2A + глобальный сдвиг по двум сценам (подогнан по этим же сценам, круговая оценка) | 31/46 | 0 | 0.32 ‰ |
| L2A, медиана воды сцены (SCL=6) → медиана воды MARIDA (`harmonize="water_median"`) | 28–33/46 | 5 | 0.29–0.39 ‰ |
| L2A, «оракул» (сдвиг к rhorc той же сцены) | 37/46 | 0 | 0.51 ‰ |

- Вывод: на L2A модель теряет примерно 40–45 % полноты и помечает примерно вдвое меньше пикселей, то есть на живых сценах она **консервативна** и занижает находки. Оконные признаки делают модель заметно устойчивее: у модели `min` на L2A найдено 11/46 против 26/46 у `win`.
- Как смягчить: (1) в L6 **не обрезать отрицательные значения** L2A, хранить float как есть; (2) в предиктор добавлена опция `harmonize="water_median"` (по умолчанию выключена): сдвиг каждого канала так, чтобы медиана открытой воды сцены совпала с медианой Marine Water из MARIDA train. Для маски воды нужно передать `water_mask=(SCL==6)`: встроенная спектральная маска оказалась плохой, с ней найдено 9/46. Эффект нестабилен (+2…+16 найденных MD и +1…+5 FP), доказательная база — одна сцена и 46 px; (3) фотометрическая аугментация при обучении (`bin_win_aug1`) — см. experiments_l3.md: на val +0.005 (не принято), на L2A вместе с harmonize даёт 36/46 при 1 FP — лучший вариант для живых сцен, но по правилу val он не принят; (4) по SPEC §5.5 основной слой демо — MDD (обучен на L2A), L3 — второй слой с подписью о сдвиге домена.
