# Эксперименты: UNet на MARIDA, только val

Метрика та же, что у LightGBM только на MARIDA (LightGBM-MARIDA): F1/IoU класса Marine Debris по пулу всех 213 102 размеченных пикселей val (ignore=0, MD = 1 075 px). Порог MD в каждом прогоне подбирается по F1 на val (сетка 0.02..0.98, шаг 0.01). В отчёт идёт модель **последней эпохи**, ранней остановки по val нет. Каждая конфигурация обучена на seed 0/1/2, среднее ± std считается с ddof=1. Test не читался: кэш строится только из train/val.
Правило принятия: F1 MD val ≥ 0.9059 (LightGBM-MARIDA, 3 seed) + max(0.01, 2×std), где std берётся наибольшим из шумов LightGBM-MARIDA (0.0025) и UNet.
Сырые результаты: `out/l4_unet/run_<exp>_s<seed>.json`, `out/l4_unet/stack_<exp>.json`, `out/l4_unet/evalpred_<exp>.json`. Логи: `out/gpu_queue/logs/*unet*`. Веса: `weights_exp/unet/<exp>_s<seed>/`.
Запуск: `scripts/train_unet.py train --seed <s> --exp <exp> --set <override>` (через GPU-очередь), затем `scripts/train_unet.py stack --exp <exp>`.

База U0 (`configs/unet.yaml`): smp.Unet(resnet34, imagenet), вход 19 каналов (11 каналов + FDI, FAI, NDVI, NDWI, NDMI, SI, BSI, NRD), нормализация: обрезка по перцентилям 0.1/99.9 train и z-score. Задача бинарная (MD против остальных размеченных классов). Loss: CE с весами [1, 5] и ignore для неразмеченных плюс soft Dice на MD. Аугментации D4 (флипы и повороты на 90°). AdamW lr 5e-4, wd 1e-4, cosine с прогревом 2 эпохи, 60 эпох, batch 16. Патчи с MD показываются ×3 за эпоху. Обучение fp32, весь train лежит на GPU в fp16.

Детали и проверки:
- **Детерминизм.** Лоссы U0 и U1 на seed 0 совпадают поэпохово (0.3333 на 10-й эпохе, 0.0759 на 60-й), и smoke-прогон дал те же первые две эпохи. Обучение воспроизводимо (cudnn deterministic, без TF32).
- **Путь инференса.** Все 6 бинарных моделей перепроверены через рабочий предиктор `macroplastic.models.unet.load_predictor` (fp32, тайлинг, CPU): F1 совпадает с оценкой при обучении до 4-го знака. Общая метрика `binary_scores` даёт те же TP/FP (стоит assert в скрипте). Стек считается по вероятностям UNet, сохранённым в fp16, отсюда расхождение не больше 0.0002 F1 (0.8954 против 0.8952 у U1 s2).
- **LightGBM-MARIDA в стеке** — вероятности `weights/lgbm` на val (F1 0.9078, TP/FP/FN 980/104/95, совпадает с reports/l3_lgbm.md).
- **Кривая val по эпохам шумная.** Для U0 s0 по эпохам 30/40/50/60: 0.865 / 0.858 / 0.897 / 0.882. EMA сглаживает хвост (U1 s0: 0.871 / 0.884 / 0.894) и уменьшает разброс по seed с 0.0108 до 0.0061. Отсюда же большой вклад std UNet в бар принятия.
- **Калибровка.** У бинарного UNet без EMA оптимальный порог очень низкий (0.05–0.20): CE с весом 5 и Dice сдвигают вероятности. У стека порог 0.42–0.57.
- **Где стек выигрывает (U1 s0, пороги LightGBM-MARIDA 0.37 / UNet 0.34 / стек 0.57).** Ложные MD на судах: LightGBM-MARIDA 22, UNet 30, стек **4**. На Mixed Water: 8 / 12 / 5, на пене: 1 / 8 / 0, на Sparse Sargassum: 13 / 20 / 10. На **Natural Organic Material** не выигрывает никто: 56 / 54 / 54 из 92 px. Обе модели путают органику с мусором одинаково; похоже, что эти классы спектрально неразличимы (вопрос к разметке). Полнота MD у стека 0.904 при 0.912 у LightGBM-MARIDA; прирост идёт от снижения FP: 73–93 против 104.
- **Бутстрэп по 12 сценам val, парный (стек U1 минус LightGBM-MARIDA).** Seed 0: +0.009 (95 % интервал +0.004…+0.028). Seed 1: +0.007 (−0.005…+0.022). Seed 2: +0.009 (+0.005…+0.021). Выигрыш стека по сценам устойчив по знаку, но мал. Сама LightGBM-MARIDA по сценам имеет std 0.029.
- **Оптимизм стека.** Вес смеси и порог подобраны на той же val, что и оценка. Реальный прирост на новых данных скорее меньше +0.01.
