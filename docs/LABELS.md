# LABELS — единая схема меток: материал, форма, контекст, сенсор

INBOX §30 п.4 (агент 17), исполнитель L123. Таблица соответствий — `data/labels_map.csv`; код — `src/macroplastic/labels/`; тесты — `tests/test_labels.py`.
Все числа меток посчитаны по скачанным файлам (`python -m macroplastic.labels.recount --check`), а не взяты из статей или README.

## 1. Схема
Каждая исходная метка хранится как есть (`source_label`). Рядом с ней стоят канонические поля:

| поле | значения | правило |
|---|---|---|
| **material** | plastic / organic / metal / other / unknown | Есть только у предмета (`role=item`) или спутникового скопления (`aggregation`). У фона и ложных объектов (судно, облако, пена, волна) материала нет. |
| material_confidence | sure / unsure («не уверен») | `sure` — материал прямо назван в метке (PET bottle, soft plastics, Metal, processed wood). `unsure` — материал выведен из формы (buoy → вероятно пластик) или не указан. |
| **form** | bottle, bag, film, packet, container, fragment, foam_item, net, rope, buoy, tire, wood, vegetation, animal, clothing, vessel … | Заполняется **только там, где форму разметил источник**. Для `sensor=satellite` форма запрещена: на S2 нет «бутылок». |
| **context** | floating_water / river / shore / ship / wake / cloud / sunglint | Где снят предмет или фон. |
| **sensor** | satellite / VHR / aerial / UAV / ship / bridge | Платформа съёмки. FML снят камерой надводного аппарата, поэтому `ship`. |
| role | item / aggregation / background / negative | `item` — отдельный предмет. `aggregation` — пятно или полоса на спутнике. `negative` — то, что похоже на мусор, но им не является (пена, водоросли, судно, кильватер, облако). |
| origin | anthropogenic / natural / unknown | Происхождение: обработанная древесина — антропогенная органика, ветки и гиацинт — природная. |

**Пенопласт ≠ морская пена.** «foam plastics» (TOCL) — предмет с material=plastic и form=foam_item. «Foam» (MARIDA/MADOS) — пена на воде: это фон (`negative`), материала у неё нет. Тест `test_sea_foam_is_not_polystyrene` это проверяет.

**«Всё = пластик» запрещено.** Если в наборе несколько классов и хотя бы в одной метке материал не назван явно, свести все метки к plastic нельзя. Валидатор отклоняет такую таблицу (`test_all_plastic_mapping_is_rejected`).

### Находка: в число ADIS входят животные и растения
В 98,5 % отрезков `n_objects>5cm` из `Segments.csv` равно числу **всех** объектов отрезка в `Objects.csv`. Чисто пластиковых классов для такого совпадения не хватает: они дают его только в 95,6 % отрезков. На классы animal и plant приходится 1 588 из 22 184 объектов в отрезках (7,2 %).

Значит, подпись «плавающий пластик > 10 см» у полевого прогноза ADIS точна лишь с оговоркой: это «объекты детектора ADIS > 10 см; 7 % из них классифицированы как животное или растение». Пересчёт: `python -m macroplastic.labels.recount --datasets ADIS`.

## 3. Счётчик по фото: «состав по классам» (правило записано 26.09 06:20–06:30, до проверки)
Число по классу материала M показываем, только если выполнены все три условия:
1. M **явно размечен** в обучающем наборе: у всех исходных меток, сведённых к M, `material_confidence=sure`.
2. У модели есть **матрица ошибок на отложенных данных**, независимых по месту или сессии.
3. На этих данных:
   - не меньше 30 предметов класса;
   - точность ≥ 0,7 и полнота ≥ 0,7.

Иначе ответ — **«всего предметов, состав не определён»**.

| режим «Фото» | модель | состав |
|---|---|---|
| камера у воды (FML) | один класс garbage | «всего предметов, состав не определён» — материал в разметке FML не указан |
| аэро/дрон (Winans) | 8 классов объединены в «предмет» | «всего предметов, состав не определён»; эксперимент M1 — ниже |
| спутник (зоны, §33) | — | всегда «состав не определён»: только «подозрительный плавающий материал» против фона, форм и материалов нет |

Код: `macroplastic.labels.composition_for(survey, boxes, card, box_materials=None)`. L109 подключает его в `/api/v3/photo/count` (поле `composition`) и в «Фото» v2 (строка «Состав»).

**M1 (аэро, Winans).** Правило записано в `docs/LOG.md` в 06:30. Детектор на 8 исходных классах, разбиение L109 по месту. Показывать можно не больше двух материалов — organic и metal: пластик в Winans выведен из формы и не показывается ни при каком качестве. Дополнительно MAE числа класса на чип должна быть ниже бейзлайна «число рамок × доля класса в train». Результат (`reports/labels/material_winans.json`) — test, 397 чипов, считался один раз. Материал рамки берём по рамкам счётчика L109 (порог 0,8, IoU ≥ 0,5).

| материал | n на test | точность | полнота | MAE на чип: модель / бейзлайн | решение |
|---|---|---|---|---|---|
| органика (processed wood) | 68 | 0,75 | 0,74 | 0,39 / 0,61, ДИ95 разности [−0,29; −0,16] | **показываем** как «дерево (обработанное)» |
| металл | 33 | 0,50 | 0,30 | 0,19 / 0,27 | нет: низкие точность и полнота |
| пластик (буи, сети, лини) | 642 | 0,86 | 0,87 | 0,89 / 1,25 | нет: материал выведен из формы, в разметке его нет |
| другое (шины) | 73 | 0,86 | 0,92 | 0,10 / 0,35 | нет: резина выведена из формы |

Итог для «Фото → аэро»: рамки делятся на «дерево (обработанное): k» и «состав не определён: n − k».

Оговорки:
- проверено только на отложенных участках того же набора (Гавайи, берег); на другом источнике не проверено;
- качество измерено при пороге 0,8;
- дерева найдено 111 из 166.

Для камеры у воды (FML) и для спутниковых зон — «состав не определён».

Код для API — `macroplastic.labels.material_winans.composition_aerial(image, boxes)`.

## 5. Как пересчитать
- `python -m macroplastic.labels.recount` — числа меток по локальным файлам (данные наборов лежат вне git).
- `python -m macroplastic.labels.recount --check` — сверить с `data/labels_map.csv`.
- `python -m macroplastic.labels.targets` — таблица раздела 4.
- `python -m pytest -q tests/test_labels.py`.
- M1: `python scripts/gpu_queue.py submit --name l123_m1b -- .venv/Scripts/python.exe -c "import sys; sys.path.insert(0, 'src'); from macroplastic.labels.material_winans import main; main(['train'])"`, затем на CPU `PYTHONPATH=src python -m macroplastic.labels.material_winans score`.
