## Дополнительно по п.5

- **Производные ответа в признаках.** Не используются. В `selection.py` утечками считаются поля с префиксами `concentration_`, `reported_`, `parent_` и поля `items_count`, `density_numerator_items`, `source_*_items`; проверка — `assert_no_leak()`. Тесты: `tests/test_case_concentration.py::test_no_leak_features`, `test_allowed_features_exclude_explicit_leaks`, `tests/test_case_conc_model.py::test_no_leak_fields_in_X`. Площадь A — только вес или offset, в признаки не входит.
- **Соседство событий.** Группа — день рейса. Фолд — непрерывный участок маршрута. Буфер 1 сут от test (5 событий S2 не используются). Более слабые схемы разбиения — по событиям, «день × 1°», «100 км / 2 сут» — сохранены в `reports/case_splits/` только для сравнения: они завышают качество.
- **Независимых оставшихся данных нет.** Отложенный test S2 и S1 использован один раз, других размеченных событий того же профиля нет. Ограничение указано явно: test не абсолютно нетронутый (ранняя разведка), а покрытие интервала на test служило для выбора метода.
- **Сравнение модели и медианы на одних событиях** хранится в `reports/case_conc/final_test_predictions.csv`: эталон, прогноз модели, прогноз медианы, принадлежность к выборке. MAE пересчитывается из этого файла. Основная модель результат S2 не улучшила.
- **Три разных интервала подписаны по-разному.** Общий показатель обследованных полос: 53.9 [39.7–70.4], бутстреп по дням. Прогноз одного нового события: 10.0–160.3. Неопределённость спутниковой оценки не оценена: сценарий PLP 470–670 бутылок на пиксель — не ДИ.
- **Сценарий PLP (шт./км² по снимку).** Калибровка — 2 пикселя на 2 датах искусственных мишеней PLP2019. Независимой проверки на тех же мишенях нет: пар «снимок + число предметов» по природному мусору — 0. Поэтому это исследовательский сценарий, а не результат (`configs/zone_estimate.yaml`).
