## 0. Как демо встроено в речь

Выступление целиком (4 минуты, слайды + демо) — `docs/SPEECH.md`; тот же текст в заметках докладчика `reports/deck.pptx`. Внутри речи демо занимает **1:50–3:05** и идёт по сокращённой версии §1: обзор → Гондурасский залив и карточка находки → зона №1 («Почему это место первое») → дрейф ▶. H3 3D, сравнение районов и вкладка «Проверка» — только если жюри дало отдельное время на демо или спросило; тогда используйте полный §1 ниже. Если демо не поднялось, слайды 6–8 деки — скриншоты тех же экранов, текст тот же; действия — по плану Б (§2).

## 2. План Б

### (а) Пропал интернет

Что произойдёт само, проверено `scripts\offline_check.py` (отчёт: `reports\offline_check.md`):
- сайт, данные, шрифты и иконки — локальные, всё работает без сети;
- тёмная подложка (CARTO) и «Спутник» (Esri) без сети недоступны. Приложение само переключается на подложку **«Без»** и показывает тост «…офлайн-режим»;
- на подложке «Без» видны однотонный тёмный фон и наши true-color вырезки Sentinel-2. Снимок, пятна, вероятность, H3, зоны, дрейф и сравнение работают, ошибок в консоли нет.

Что делать:
1. Левая панель → **Подложка → «Без»**. Если приложение уже переключилось само, ничего не делать. «Тёмная» и «Спутник» не нажимать: будет повторная ошибка и тост.
2. Сказать: «Внешняя подложка из интернета недоступна, но всё наше считается и хранится локально: снимки, находки, индекс, зоны, прогноз дрейфа. Сервис рассчитан на работу в поле без сети».
3. Учесть, что на обзорной карте в режиме «Без» нет береговой линии: метки районов висят на тёмном фоне. Обзор проговорить быстро и сразу перейти в район, там вырезка снимка даёт весь контекст.

Можно заранее начать показ в офлайн-режиме: http://127.0.0.1:8000/?b=none

### (б) Сервис не стартует

Проверка: http://127.0.0.1:8000/health должен ответить 200.

Из рабочей папки (полные данные, 18 районов), в PowerShell из корня:
```powershell
.venv\Scripts\python.exe -m service --port 8000
```
Сервис поднимается примерно за 2 с. Если порт занят, добавьте `--port 8080` и откройте http://127.0.0.1:8080.

Из чистого клона одной командой:
```powershell
git clone https://github.com/azama2t/final-cosmohack.git; cd final-cosmohack; powershell -ExecutionPolicy Bypass -File run.ps1
```
- Сколько ждать: около 3,3 мин при тёплом кэше pip (проверка на чистом клоне). На чужой машине без кэша — 10–20 мин: больше всего весит PyTorch CUDA. Для показа карты GPU не нужен: `run.ps1 -Cpu` ставит `requirements-cpu.txt` с CPU-сборкой PyTorch (около 1,6 ГБ вместо 5,7 ГБ). Если `nvidia-smi` нет, `run.ps1` выбирает CPU-сборку сам.
- Фронт собирать не нужно, `service\static` лежит в репозитории.
- В чистом клоне есть только демо-набор `service\demo`: 3 района (Залив Гуанабара, Мумбаи, Гондурасский залив), 6 дат. Полный слой `service\data` (18 районов, ~490 МБ) в git не входит. Его нужно заранее скопировать на флешку и указать: `run.ps1 -DataRoot <путь>\data`.

### (в) Всё упало

Включите запасное видео тура. Это запись в браузере, звука нет, комментируйте голосом по таблице из §1.
- Запись `reports\screens\final\tour.webm` (25.09, до L43) идёт по Мумбаи: с тех пор тур открывает Гондурасский залив. Если видео не перезаписано командой ниже, комментируйте Мумбаи по кадрам, а не по таблице §1. Более старые записи (`iter5`, `final_real`) показывают Манилу и прежний рейтинг — не использовать.
- `reports\screens\` в git не входит (`.gitignore`). Скопируйте видео на рабочий стол и на флешку заранее.
- Перезаписать после финальной сборки фронта (сервис должен работать):
  ```powershell
  .venv\Scripts\python.exe scripts\screenshots.py --base-url http://127.0.0.1:8000 --out reports\screens\final --gl gpu --extra --l20 --video
  ```
  Результат — `reports\screens\final\tour.webm`. Проверьте, что он открывается в браузере: перетащите файл в окно Chrome.
- Последний рубеж: кадры `reports\screens\final\*.png` или слайды `reports\deck.pptx`.

## 3. Чек-лист за 10 минут до выступления

1. **Закрыть лишнее:** мессенджеры, почту, уведомления. Включить режим «Не беспокоить» (Windows: Фокусировка внимания).
2. **Режим «не спать»:**
   ```powershell
   powercfg /change standby-timeout-ac 0
   powercfg /change monitor-timeout-ac 0
   ```
   Отключить заставку. Ноутбук подключить к зарядке.
3. **Никто не пересобирает фронт.** `npm run build` удаляет старые файлы `assets\*.js`, и уже открытая вкладка ломается: сравнение, H3 и график по датам не загружаются (404 на ленивые чанки; поймано этой проверкой). После любой сборки — F5.
4. **Прогреть сервис:**
   - `http://127.0.0.1:8000/health` → 200;
   - открыть сайт, один раз пройти Гондурасский залив: снимок, H3, зона №1, дрейф, сравнение с Гуанабарой. Так прогреются кэш браузера и ответы API.
5. **Открыть вкладку** на обзоре: http://127.0.0.1:8000/ (или `/?b=none`, если сеть ненадёжна). Масштаб страницы 100 % (Ctrl+0), полноэкранный режим F11.
6. **Проверить экран:**
   - проектор в режиме «Дублировать» (Win+P);
   - разрешение 1920×1080. На 1366 интерфейс тоже проверен, но панели занимают больше места.
7. **Звук и микрофон:** проверить, если видео будет со звуком или выступление онлайн.
8. **Запасное видео** — на рабочем столе, открыто во второй вкладке браузера.
9. **Сеть:** если Wi-Fi площадки нестабилен, сразу работать в режиме «Без». Лишние переключения на глазах у жюри ни к чему.
10. **Офлайн-самопроверка (по желанию, ~1 мин):** `.venv\Scripts\python.exe scripts\offline_check.py --no-baseline`. Код возврата 0 означает, что карта и сцена поднимаются без интернета.
