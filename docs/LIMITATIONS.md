# LIMITATIONS — что не доказано и что не сделано

Короткий указатель. Развёрнуто — README, раздел «Ограничения», и отчёт [../reports/report.pdf](../reports/report.pdf).

## Что НЕ следует из спутникового снимка

- **Нет шт./км² по снимку.** Калибровочных пар «снимок → шт./км²» 0; синхронных пар снимок ↔ полевой счёт среди событий организаторов 0; на 11 парах связь признаков снимка с полевой плотностью не отличается от случайной воды той же сцены. Концентрация на карте — медиана профиля акватории по полевым данным, не измерение участка.
- **Физический предел разрешения.** Пиксель Sentinel-2 — 10 м; предметы профиля 2.5–50 см; поштучно различимо 0 %. Видны только скопления; маска или индекс — это площадь, а не число предметов.
- **Нет массы** (кг, т) и **нет состава**: детектор бинарный (класс MARIDA Marine Debris = любой плавающий материал).
- **Нет классификации водорослей.** Флаг «вероятно органика» (NDVI / FAI) — эксперимент, на разметке не проверен ([ORGANIC.md](ORGANIC.md)).
- **Дрейф — модельный сценарий** на горизонте не более 72 ч с коридором вероятности 50 % / 90 %; в проверке на парах снимков прогноз не лучше «нулевого дрейфа» (7/18 против 7/18).
- **Детектор проверен на MARIDA** (обработка ACOLITE); на снимках L2A без разметки его точность не измерена, F1 test на них не переносится.

## Данные и проверка

- Мало независимых полевых данных: S2 — 63 события одного рейса; ДИ широкие; модель концентрации на отложенном test не лучше медианы, поэтому используется медиана.
- Отложенный test концентрации не абсолютно нетронутый: ранняя разведка бейзлайнов видела все события профиля.
- Счётчик по фото — фото с воды или с воздуха, **не спутник**; шт./км² по фото — только на кадрах с известной площадью.

## Не сделано / не проверено

- **NASA — только контекст.** Снимки NASA GIBS (MODIS / VIIRS) имеют пиксель в сотни метров; детектор на них не запускается — пластик на таком разрешении не виден. Детекция в «Реальном времени» идёт только на новых снимках Sentinel-2.
- **Дополнительные слои — не измерение.** «Дроны» — детальные кадры открытых наборов (дрон / судно / берег, не спутник); у наборов нет дат съёмки, поэтому дорожка «Дроны» на таймлайне пустая. «Свежий Sentinel-2» — автоматически, не проверено человеком. PRIME MODE — демо-режим по запросу жюри: изображения и числа демонстрационные (числа — из строк CSV организаторов), метрик качества нет.
- **Docker** — <!--DOCKER-->Dockerfile и docker-compose.yml есть; проверка из чистого клона идёт, до её итога — не проверено.<!--/DOCKER-->
- **Linux** — <!--LINUX-->команды в [DEPLOY.md](DEPLOY.md); на чистом сервере не проверено.<!--/LINUX-->
- **macOS** — не проверялось.
