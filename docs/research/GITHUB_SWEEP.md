# GITHUB_SWEEP — проход по GitHub и GitVerse (задание команды с правкой; «поиск на GitHub», 26.09 06:00–06:15)

## ИТОГ (≤ 10 строк)
1. Открытых репозиториев других команд КосмоХакатона 2026 **по нашему кейсу (макропластик) не найдено** ни на GitHub, ни на GitVerse: 30+ поисков (cosmohack/kosmohack/космохакатон/macroplastic/макропластик/MARIDA/даты ≥ 01.09.2026). Найдено ~40 публичных репозиториев КосмоХакатона 2026 по **другим** кейсам (пожары, паводки, вегетация, спутниковая группировка, ВКД на МКС, топливо): для нас бесполезны. Сдача идёт на GitVerse, репозитории финалистов, видимо, закрыты до дедлайна: повторить проход около 12:00 тем же скриптом.
2. Лучшее для счётчика: **Chagneux и др. 2023, Computo** (`computorg/published-202301-chagneux-macrolitter`, CC-BY-4.0). Ошибка подсчёта раскладывается на пропущенные, ложные и повторные предметы (метрики CountPR/CountRe), а повторы убираются трекингом. Ответ на и на вопрос «из чего состоит MAE».
3. Дедупликация по перекрывающимся кадрам БПЛА: **`Ikram-c/UAV_unsupervised_litter_counter`** (Apache-2.0). Гомография пары кадров → перенос рамок → пары пересекающихся рамок одного класса → связные компоненты графа = уникальные предметы. Код маленький (31 КБ), брать можно с атрибуцией, но только если у нас есть серии с перекрытием.
4. Полосы (windrows): **`Dimitone14/FLODAS`** (код MIT; веса CC-BY-NC-4.0 лежат в zip на 2.03 ГБ, качать нельзя). U-Net для 8 каналов SuperDove от автора Papageorgiou 2026 (Г1-6). Для S2 веса не подходят; из кода полезна постобработка: порог, минимальный размер, отступ от края, сглаживание, изополосы вероятности.
5. Камера на мосту → статистика плавающего мусора с калибровкой камеры: **`Deltares-research/plastic-monitor`** (MIT). Интерфейс и отчёты: **TideTrace** (MIT, офлайн-консоль с видами «Метод» и «Данные»), **Pelago** (MIT, S2: кандидат → ручная проверка → подтверждённый участок), **TRIDENT** (без LICENSE, только идеи: площадь воды на кадре через GSD, класс «отброшено: пена/блик/след/саргассум»).
6. Экспорт полевых данных в формате EMODnet: `nodc-it/marine-litter-manager` (CC0). Байесовская вероятность «встретить ≥ 1 предмет»: `hammerdirt-analyst/finding-one-object` (GPL-3, только идея).
7. Уже известное (DebrisScan, Trash_Track, marinedebrisdetector, MADOS, POS2IDON, floatingobjects, NASA IMPACT, SAHI, LitterLines и др., 44 репозитория) повторно не разбирал: см. `docs/research/gleb_deep_research/REPOSITORIES_AND_MODELS.md`.
8. Ничего не заимствовано и не скачано, кроме README и JSON через API/raw (< 1 МБ суммарно). Code search без токена недоступен, `gh` не установлен, лимит WebSearch исчерпан: работал через REST-поиск репозиториев (без ключа), raw.githubusercontent и API поиска GitVerse.

## Как искал
- GitHub REST `search/repositories` без ключа (10 запросов/мин; 120 запросов: названия, описания, `in:readme`, `topic:`, `user:`, фильтры `created:/pushed:` ≥ 2026-08-15), README через raw.githubusercontent.com, лицензия и последний коммит через `repos/{r}` и `commits?per_page=1` (~35 вызовов). Скрипт и сырые ответы лежат в `out/l120_github/` (не в git): `search.py`, `q_*.txt`, `search_*.json`, `readme/`.
- GitVerse: `https://gitverse.ru/api/repos/search?q=…` (поиск только по имени) и `api/repos/{owner}/{repo}/contents`; просмотрены корни и README 11 кандидатов.
- Недоступно: GitHub code search (нужна авторизация), `gh` CLI (не установлен), WebSearch (лимит сессии 200/200), Papers with Code (не проверял: поиска нет).
- Лицензию брал из API GitHub. Если там NOASSERTION, открывал файл LICENSE: у TideTrace это MIT, у GBM «All rights reserved», у uav-litter-detection CC BY 4.0.
