# Оценщик «снимок S2 → число штук» (двигатель открытий), версия наборов v2

Зачем. Открытия в автоматическом поиске методов получаются только там, где есть быстрый объективный оценщик на реальных данных. Этот оценщик прогоняет любой метод на **зафиксированных** наборах и пишет **раздельные** показатели по каждому набору в `docs/research/discovery/LEADERBOARD.csv`.

**Главное ограничение.** Проверка «спутник → число» на природе возможна только на наборе A5 (природные синхронные пары). В v2 он пуст. Пока в A5 меньше 5 пар, **ни один метод не называется «природным счётчиком»**: так написано в каждой строке лидерборда и в выводе оценщика. Выводы по A1 относятся только к искусственным мишеням.

## Где что лежит

- Код:
  - `scripts/discovery/harness.py` — оценщик;
  - `scripts/discovery/lib.py` — полосы, FDI, маска воды, текущий детектор с кэшем;
  - `scripts/discovery/build_sets.py` — сборка наборов;
  - `scripts/discovery/baselines/` — б1–б3.
- Состав и правила v2: `configs/discovery_sets_v2.yaml` + `.sha256`. Блок `frozen` хранит sha256 манифеста, меток и типов плиток. Записан до первого прогона на v2.
- v1 (одна сводная формула, оставь-одну-дату) не удалён: `configs/discovery_sets.yaml`, строки — `LEADERBOARD_v1.csv`. С v2 не смешивается.
- Окна S2 лежат локально в `data/discovery/v2/` (вне git). Прогон бейзлайна занимает 3–10 с.
- Тесты: `tests/test_discovery_harness.py`.

- **Воздержание** (`None`) — правильный ответ там, где видимого сигнала нет. На A2 оно засчитывается как успех. На A1 воздержание считается как N̂ = 0 и интервал не покрывает N; на A4 — как «не обнаружено».

## 2. Как запустить

```
set CUDA_VISIBLE_DEVICES=-1
.venv\Scripts\python.exe scripts\discovery\harness.py run scripts\discovery\methods\my_unmix_v1.py --note "k=5, априор ADIS"
.venv\Scripts\python.exe scripts\discovery\harness.py board
.venv\Scripts\python.exe scripts\discovery\harness.py check --deep
```

- Строки в лидерборд пишет **только** `harness.record`, его вызывает `run`.
- `--sets …` и `--no-record` — отладочные прогоны, они не записываются.
- Предсказания каждого прогона сохраняются в `data/discovery/v2/runs/<метод>__<хэш>.csv`, ложные зоны по окнам — в `…__zones.csv`.

## 3. Наборы и показатели v2 (раздельные колонки)

| набор | что | n | показатели |
|---|---|---|---|
| **A1 мишени (A\*)** | PLP2018 (3 738), PLP2019 ×5 (бутылки по дрону; пакеты не посчитаны), Maathuis 2026 ×6 (360) + 2 контроля (0), Лимасол 2018 (1 500); PLP2021 ×21 — только доля (сетка HDPE ≈ 616 м², истина в м²). **Разбиение — оставь-одну-КАМПАНИЮ** (PLP2018 / PLP2019 / Maathuis / Лимасол / PLP2021) | 15 дат со счётом + 21 по доле | `E1_err` — ошибка числа, mean \|log10((N̂+1)/(N+1))\|; `B1_bias` — смещение (знаковое; > 0 — завышение); `C1_cover` — покрытие объявленного [lo; hi]; `Ec_plp2021_cover` — ошибка площади, если есть `predict_cover` |
| **A2 без видимого сигнала** | 66 пар ADIS + 11 пар CSV: плотности поля дают покрытие пикселя 10⁻⁷–10⁻⁴, то есть сигнала на снимке нет | 77 | `ABST2` — доля пар, где метод **правильно воздерживается** (None или N̂ < 1 в окне 1.64 км²); штраф — 1 − ABST2; справочно `G2` — «тысячи шт./км² при c < 100» |
| **A3 фон** | MARIDA test (вода, пена, суда, облака, тени, саргассум, органика, волны, следы, мутная вода), суда Финляндии, облака CMC | 427 окон | `FP3` — доля окон с N̂ ≥ 1 в ROI 32×32 (порог ≤ 1 %); `Z3_zones_km2` — **ложные зоны** на полных окнах A2 и A3 (подробнее ниже) |
| **A4 Cózar 2024** | нити полос (уровень B) | 35 | `R4_detect` — только **полнота обнаружения**: доля нитей с N̂ ≥ 1. Плотность не проверяется |
| **A5 природные синхронные пары** | только пары, подтверждённые критиком пар. В v2 пусто; кандидат — ISPRA ER604 (16.09.2019 × S2B_32TQQ) | 0 | `n_A5`, `natural_counter` |

Как считаются ложные зоны `Z3`:
- Каждое окно A2 и A3 делится на 16 плиток 32×32. Всего 8 037 плиток, около 823 км².
- Зона — 4-связная группа плиток с N̂ ≥ 1. Показатель — число зон на км²: всего и по типам `Z3_ship`, `Z3_foam`, `Z3_organic`, `Z3_cloud`, `Z3_glint`, `Z3_waves_wakes`, `Z3_water`.
- Тип плитки:
  - разметка MARIDA (≥ 3 пикселя класса);
  - центр окна судна Финляндии;
  - ручная маска CMC;
  - иначе — блик (вода > 50 % плитки и медиана B11 воды > 0.03) или вода.
- Плитки с разметкой «мусор» MARIDA исключены.

Справочно в лидерборде есть `ref_score = E1 + (1 − ABST2) + 10·max(0, FP3 − 0.01) + 0.25·(1 − R4)`. Он нужен только для сортировки, вывода по нему не делается.

**В продукт** (замена б1 в карточке зоны) метод идёт только при всех условиях сразу:
- верхняя граница 95 % ДИ парной ΔE1 против б1 (оставь-одну-кампанию) меньше 0;
- ABST2 не ниже, чем у б1;
- FP3 не больше max(FP3 б1, 1 %);
- Z3 не больше, чем у б1.

Даже при `PASS` метод остаётся «оценкой по искусственным мишеням», а не природным счётчиком.

Бутстреп: 2 000 повторов, кластерный. Группы: дата (A1), пара (A2), сцена или патч (A3, A4, Z3).

Версии: новый состав наборов (новые мишени, пары A5 после критика) — это новая версия. Для неё нужны новый каталог `data/discovery/vN`, новый yaml и новый sha256. Баллы разных версий не смешиваются.

## 4. Что запрещено

1. **Подбирать под A1.** Параметры задаются только в `fit`, а `fit` не видит удерживаемую кампанию. Каждое изменение кода — это новая строка лидерборда, и все строки остаются.
2. **Поля-ответы как признаки.** Нельзя читать `labels.csv`, `tile_types.csv`, `p1_*.csv`, `adis_candidates.csv`, `pair_quality.csv`, `registry_cozar*.csv`, `features_*.npz` с метками. Нельзя использовать id образца, класс фона, плотность поля.
3. **Угадывать набор по meta** (наличие SCL, дата, координаты, размер ROI) и ветвиться по нему.
4. **Учиться на окнах A2–A5**, в том числе на MARIDA test. Источник обучения нужно указать в `--note`.
5. **Менять наборы, правила или оценщик ради метода.** Такие изменения делаются только новой версией, объявленной заранее.
6. **Называть метод «природным счётчиком»**, пока в A5 меньше 5 пар.

## 5. Ограничения

- A1 — это искусственные мишени: бутылки PET, у Maathuis — берег реки. Кампаний со счётом всего 4, поэтому ДИ широкие.
- В PLP2019 пакеты не посчитаны. PLP2021 — одна сетка; состояние по датам (плавает или притоплена) не учитывается.
- б1 и б3 используют 470/670 предметов на пиксель. Это **исследовательский сценарий** по мишеням PLP2019 (допущения: предметы размера бутылки 1.5 л, покрытие 28–40 %), а не доверительный интервал. Эти числа получены на датах, которые входят в A1, поэтому на A1 б1 оптимистичен.
- В A2 ROI — это квадрат 1.28 км вокруг середины отрезка судна, а не полоса обзора.
- Типы плиток «блик» и «вода» определены по спектральному правилу, а не по разметке.
