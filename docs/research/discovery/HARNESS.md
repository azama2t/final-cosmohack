# Оценщик «снимок S2 → число штук» (двигатель открытий)

Зачем. Открытия в автоматическом поиске методов получаются только там, где есть быстрый объективный оценщик на реальных данных. Здесь он есть: любой метод получает один балл на **зафиксированных** наборах. Все варианты сравниваются в одной таблице `docs/research/discovery/LEADERBOARD.csv`.

- Код: `scripts/discovery/harness.py` (оценщик), `scripts/discovery/lib.py` (полосы, FDI, маска воды, текущий детектор с кэшем), `scripts/discovery/build_sets.py` (сборка наборов), `scripts/discovery/baselines/` (б1–б3).
- Состав наборов, формула балла, запреты: `configs/discovery_sets.yaml`, хэш — `configs/discovery_sets.yaml.sha256`. Записано до первого прогона любого метода.
- Окна S2 лежат локально в `data/discovery/v1/` (вне git, ≈ 0.1 ГБ). Прогон метода идёт без сети и занимает минуты.
- Тесты: `tests/test_discovery_harness.py`.

Метод — это один python-файл, например `scripts/discovery/methods/my_unmix_v1.py`:

- Помощники: `from lib import detector_prob, detector_threshold, fdi, water_mask, stack, ITEMS_PER_PX_LO, ITEMS_PER_PX_HI`. Каталог `scripts/discovery` уже лежит в `sys.path`.
- `detector_prob` — это `weights/lgbm` без гармонизации. Результат кэшируется на диске по хэшу пикселей, поэтому повторные прогоны быстрые.

## 2. Как запустить

```
set CUDA_VISIBLE_DEVICES=-1
.venv\Scripts\python.exe scripts\discovery\harness.py run scripts\discovery\methods\my_unmix_v1.py --note "k=5, априор ADIS"
.venv\Scripts\python.exe scripts\discovery\harness.py board          # лидерборд текущей версии, по баллу
.venv\Scripts\python.exe scripts\discovery\harness.py check --deep   # целостность наборов (sha256 всех окон)
```

- `run` проверяет sha256 манифеста и меток. Если состав изменён, прогон не начнётся.
- Затем `run` считает предсказания и балл с бутстреп-ДИ и печатает таблицу по наборам, по классам фона A3 и по датам A*.
- Строка в лидерборд пишется **только** функцией `harness.record()`, которую вызывает `run`. Руками строки не добавлять.
- `--sets A1` и `--no-record` — это отладочные прогоны, в лидерборд они не пишутся.
- Из Python: `harness.evaluate(predict, fit, name=..., code_sha=...)` возвращает словарь с таблицами и per-sample.
- Предсказания каждого прогона лежат в `data/discovery/v1/runs/<метод>__<код-хэш>.csv`.

Колонки лидерборда: дата, версия наборов, метод, код-хэш (sha256 файла, 12 знаков), `score` и 95 % ДИ, `E1_astar_lodo` и ДИ, `cov1`, `dE1_vs_b1` (парная разница с б1) и ДИ, `E2_field` и ДИ, `G2_thousands`, `FP3` и ДИ, `P4_cozar`, `A4_pos_frac`, n по наборам, `n_errors`, `gate_product`, время, хэш наборов, заметка.

## 3. Наборы (версия v1)

| набор | что | n | метрика |
|---|---|---|---|
| **A1 (A\*)** — главный | мишени с известным числом предметов, S2 той же даты. PLP2018 (3 738), PLP2019 ×5 (бутылки по дрону; пакеты не посчитаны), Maathuis 2026 ×6 (360) + 2 контроля (0), Лимасол 2018 (1 500). ROI 64×64 | 15 дат | `e = |log10((N̂+1)/(N+1))|`, среднее по датам, **оставь-одну-дату**; `cov1` — доля дат, где N попало в [lo; hi] |
| A2 | поле без видимого мусора: 66 пар ADIS (> 5 см) и 11 пар CSV (12-я — Landsat, не S2). ROI — всё окно 1.64 км² | 77 | `ĉ = N̂/площадь ROI`; `E2 = mean |log10((ĉ+1)/(c+1))|`; `G2` — доля пар с ĉ ≥ 1 000 при c < 100 («тысячи при единицах») |
| A3 | чистая вода и сложный фон: MARIDA test (все классы, кроме мусора: вода, пена, суда, облака, тени, саргассум, следы…), суда Финляндии, облака CMC. ROI 32×32 = 0.10 км² | ≈ 420 | `FP3` — доля окон с N̂ ≥ 1; порог ≤ 1 % |
| A4 (мягко) | нити Cózar 2024 (уровень B). ROI — пиксели нити | 35 | `P4` — доля нитей, где НЕ (N̂ > 0 и 10⁴ ≤ ĉ_in ≤ 10⁸ шт./км²) |

Полоса A4:
- Нижняя граница — из Cózar et al. 2021 (Front. Mar. Sci. 8:571796), раздел «Litter concentrations in the windrows»: «we used 1 macro-item per 100 m2 … as minimum concentrations for well-developed macro … windrows», то есть 10⁴ шт./км².
- Верхняя граница 10⁸ в тексте не названа. Это верх оси рис. 2A (данные Ruiz et al. 2020). Поэтому A4 — проверка правдоподобия, а не метка.

**Балл (меньше — лучше):** `SCORE = E1 + 0.5·E2 + 1.0·G2 + 10·max(0, FP3 − 0.01) + 0.25·P4`.

- Бутстреп: 2 000 повторов, кластерный по группам внутри набора. Группы: дата для A1, пара для A2, сцена или патч для A3 и A4.
- **В продукт** метод идёт только при трёх условиях одновременно:
  - верхняя граница 95 % ДИ парной ΔE1 против б1 меньше 0;
  - E2 не хуже, чем у б1;
  - FP3 не больше max(FP3 б1, 1 %).
- Колонка `gate_product` показывает, выполнены ли эти условия: `PASS` или `fail`.

Версии: новый состав наборов (например, новые даты A\*) — это новая версия (`v2`). Для неё нужны новый каталог `data/discovery/v2`, новый блок `frozen` и новый sha256. Баллы разных версий не смешиваются: `harness.py board` и `gate` смотрят только текущую версию.

## 4. Что запрещено

1. **Подбирать под A1.** Параметры, порог и выбор варианта задаются только внутри `fit()`, а `fit()` видит только обучающие даты (оставь-одну-дату). Нельзя крутить константу, пока E1 не станет лучше, если эту константу не выводит `fit()`. Каждое изменение кода — это новая строка лидерборда, и все строки остаются.
2. **Поля-ответы как признаки.** Нельзя читать `labels.csv`, `p1_*.csv`, `adis_candidates.csv`, `pair_quality.csv`, `registry_cozar*.csv`, `features_*.npz` с метками. Нельзя использовать плотность или число предметов, id образца или класс фона.
3. **Угадывать набор по meta** (наличие SCL, дата, координаты, размер ROI) и ветвиться по нему.
4. **Учиться на окнах A2–A4**, в том числе на MARIDA test: эти окна только для оценки. Обучаться можно на MARIDA train/val, синтетике, спектрах мишеней вне A1 и т. п. Источник обучения нужно указать в `--note`.
5. **Менять наборы, формулу или оценщик ради метода.** Такие изменения делаются только новой версией наборов и объявляются заранее.

## 5. Ограничения, которые надо помнить

- A1 — это искусственные мишени (бутылки PET, берег реки у Maathuis). В природных скоплениях калибровка не проверена.
- В PLP2019 пакеты не посчитаны, поэтому N по пакетным мишеням занижено.
- Числа 470/670 у б1 и порог 0.03 у б3 получены на пикселях тех же PLP-дат, что входят в A1. Поэтому б1 и б3 на A1 оптимистичны. Честная проверка метода с `fit()` — по оставь-одну-дату.
- В A2 ROI — это квадрат 1.28 км вокруг середины отрезка судна, а не сама полоса обзора. Сравнивается плотность, а не число.
- В A3 правило «N̂ ≥ 1 на 0.10 км²» означает не меньше ~10 шт./км² на фоне. Фон в единицы шт./км² (как у ADIS) ложным не считается.
