### T23. «Шкала вида» для агрегатов (аналогия: Bonn Agreement Oil Appearance Code — вид пятна → толщина → объём; учёт скота/палаток по площади стада/лагеря)

Правило: шкала принимается для реки, если MAE по дням ниже, чем у среднего, и 95 % бутстреп-ДИ разности (по дням) не содержит 0.

### T17. «Обратный ход агрегации» (Ciappa 2026): N в полосе = фоновая плотность поля × площадь сбора за 1–2 сут
- **Первоисточник:** Ciappa 2026, MPB, https://doi.org/10.1016/j.marpolbul.2026.119653 (открыт: аннотация — полосы растут у фронтов плотности за 1–2 сут при ветре < 5 м/с; концентрацию можно оценить, «если восстановить процесс агрегации»).
- **Идея:** связать наш основной результат (фоновая C по полю) и площадь полосы по S2: N_полосы ≈ C_фон × A_сбора, A_сбора = длина полосы × скорость конвергенции × время. Проверка правдоподобия — внутриполосные значения Cózar 2021 (набор 4 оценщика).
- **Критик:** скорость конвергенции у фронта не измерена у нас (0.01–0.1 м/с — моё допущение, не из источника); фон C для места полосы не известен (поле и снимок в разных местах); результат — сценарий с разбросом на порядки, как T09. Только как текст «путь развития».

### T18. «Уборка как перепись» (аналогия: подсчёт палаток/скота проверяют по реестру/переписи)
- **Идея:** для мусора «перепись» — полная уборка видимого скопления с поштучным отчётом в известное время (физический отбор, как 58 пятен Чаупхраи). Искать отчёты уборок видимых скоплений с N (не кг).

### T01. Гиацинт как ловушка: площадь пятен на S2 × измеренная плотность предметов в пятне (Чаупхрая, Бангкок, 03–04.2025)

- **Первоисточник:** Hagenbeek, van Emmerik, Jia, …, Rußwurm 2026, iScience, https://doi.org/10.1016/j.isci.2026.116238 (открыт: текст, PMC13266208). Данные: 4TU https://doi.org/10.4121/f771da08-8143-4a4b-9ad6-c8e711812a63.v1, CC BY 4.0 (открыт: данные — `fieldwork_datasets.zip`, 116 КБ). Классификатор гиацинта по S2: https://github.com/GielHagenbeek/Waterhyacinth_classification_Sentinel2 (не проверено — ссылка из текста статьи).
- **Проверенные числа (посчитал сам из `Physical_sampling_dataset.xlsx`, строка TOTAL совпадает):** 58 пятен, 24.99 м², 1 847 пластиковых предметов (1 863 всего) → **73.9 пласт. предмета/м²**; отбор 01–04.04.2025. Статья: пятна 0.03–2.25 м², в гиацинте в 59 раз больше пластика, чем в открытой воде; физический отбор находит в 14 раз больше, чем снимок.
- **Счёт с мостов (`Visual_couting_dataset.xlsx`):** 485 строк, 4 моста (Rama IV, Krungthep, Krung Thon, Maha Chesadabodindranusorn), 16 дат: 17, 18, 20, 21, 24, 25, 27, 28.03; 08, 10, 11, 12, 22, 23, 25, 26.04.2025; окна по 5 мин; колонки «# Plastic Items inside hyacinths», «# … outside».
- **Критик.** (1) Пятна 0.03–2.25 м² ≪ пиксель 100 м²: S2 видит только крупные скопления пятен; площадь по S2 будет смещена. (2) Мосты дают поток (шт./5 мин), а не число в участке — пара «площадь ↔ поток», уровень C (река, прокси), не A. (3) Даты S2 в марте–апреле: облачность Бангкока не проверена. (4) Наш детектор морской; нужен классификатор гиацинта (у авторов). (5) Это река, не море; перенос на море — нет. (6) Плотность 73.9/м² — одна река, одна неделя.
- **Как проверить ≤ 1 ч (П2/П3):** S2 L2A (Earth Search/PC) над Бангкоком 16.03–27.04.2025, облачность ≤ 30 %; для каждой даты S2, совпадающей с датой счёта ±1 сут, — площадь гиацинта (NDVI > 0.3 на воде как простейший прокси; или классификатор авторов) в участке ±1 км от каждого моста; Спирмен с «plastic inside hyacinths» за день. Правило до расчёта: связь принимается, если ρ > 0 и 95 % бутстреп-ДИ не содержит 0 на ≥ 6 парах «мост × дата»; иначе «площадь гиацинта по S2 не предсказывает поток пластика». Отдельно — N_участка = A_гиацинта × 73.9 [бутстреп по 44 строкам отбора].
- **Что даёт:** первую открытую пару «S2 + число предметов в тот же день» с измеренной плотностью в агрегате; для П3 — априорное распределение «предметов на м² агрегата» (природное, не бутылки PLP).
