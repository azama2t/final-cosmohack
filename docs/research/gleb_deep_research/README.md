# Последний deep research

Начните с `DEEP_RESEARCH.md`: выводы, топ-10, аналоги, архитектуры, путь к шт./км² и тесты.
`REPOSITORIES_AND_MODELS.md` содержит ссылки, описание входов/выходов, весов, данных, зависимостей и команд.
`repo_audit.json` и `audit_repositories.py` фиксируют проверку репозиториев.

Архив включает только материалы последнего deep research. Весов, моделей, скачанных репозиториев, исходных датасетов, снимков и предыдущих исследований нет.
