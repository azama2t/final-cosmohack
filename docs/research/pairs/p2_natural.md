# П2 — природные пары «снимок + счёт», обратный ход 

Файлы этой ветки:
- `docs/research/pairs/p2_natural.csv` — строки П2. Колонки как в `docs/research/cases/CASES_REGISTRY.csv` плюс «пиксели_детектора_на_месте_счёта».
- `docs/research/pairs/ispra_levels.csv` — уровни по всем 167 трансектам ISPRA, у которых есть S2 того же дня. Это кандидаты, а не пары.

- Маски — `scripts/case/pair_quality.py:process_s2`, импорт без изменений.
- Правило освещённости — `src/macroplastic/case/illumination.py`.

## Допущения и правила
- **Дрейф.** 0.1 м/с = 8.6 км/сут; 0.2 м/с — верхняя оценка с ветровым сносом. Пары ±1 сут не считаются той же кучей.
- **ISPRA.**
  - Время в файлах без часового пояса. У паромных файлов ISPRA поле GPS_time с «Z», то есть UTC.
  - Ширина полосы в файлах 2018–2020 не записана; по протоколу SNPA 2024 она ≤ 5 м.
  - У предметов старого формата нет времени.
  - Точки трека дальше 30 км от медианы отброшены. Паромные маршруты обрезаны до ±20 км вокруг предметов.
  - В двух файлах Кампании 2022 года время в исходнике испорчено (например, «82:55:00»), Δt для них не считается.
- **Окна Cózar.** Использована пиксельная рамка по трансформу STAC. Центр из файла расходится с ней на ~2 км.
- **Утверждения из новостей.** Приняты только со страниц, которые были открыты; сниппеты помечены.
