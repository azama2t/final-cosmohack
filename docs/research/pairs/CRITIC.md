# CRITIC — критик пар «снимок + число предметов»

Версия 2 — 26.09 14:25 (версия 1 — 14:21). Роль: «критик пар» (бывший «турнир»; турнир гипотез — `docs/research/discovery/TOURNAMENT.md`, теперь 1 строка в час).
Правило: пара получает вердикт только по открытым файлам. Для каждой пары — 7 проверок: (1) кадр S2 (product ID, обработка), (2) N (файл, строки), (3) площадь и контур счёта против пикселя 100 м², (4) Δt, часовой пояс, дрейф, (5) видимый сигнал на кадре (детектор/нити относительно воды), (6) лицензия, (7) независимость от обучения детектора. Повышение C → A — только если все 7 закрыты файлами.
Рабочие файлы критика (вне git): скрипт перепрогона `er604_v0.py`, результат `er604_v0.json`, вырезки `er604/<product>/`.

## Как проверял ER604 (воспроизводимо)
- Исходные файлы (вне git, скачаны П2 с портала ISPRA «Dati monitoraggio 2018–2023», Modulo 2bis Adriatico): `mod_2Bis_ER_0919-MacroplasticheFlot.csv` (строка «604,2019,9,16,12:05:49,1,44.65419,12.32386,44.63967,12.49936,1,1,150,5»), `…-MacroplasticheFlotCamp.csv` (16 строк 604), `…-Stazioni.csv` («PORTO GARIBALDI a 6 Km dalla costa», 44.661757 N 12.324947 E, глубина 12 м, тип PF — речной шлейф), `…-DD_*.csv` (словари полей). Протокол: SNPA 2024, «Schede metodologiche», раздел 10.2.1 Modulo 2bis, табл. 10.7.
- Перепрогон: `pair_quality.process_s2` без изменений, `weights/lgbm` без гармонизации, зона ±500 м и узкая ±50 м вокруг трека — тем же кодом, что у П2, но на двух обработках.
- Площадь предметов: верхняя граница по классам размера (B 2.5–5 см → ≤ 0.0025 м², C ≤ 0.01, D ≤ 0.04, F ≤ 0.25 м²) → ≤ 0.37 м² на полосу ≤ 70 000 м².
