## ИТОГ (≤ 10 строк)
1. Ни одна из примерно 55 открытых работ не даёт проверенного «шт./км² по снимку» для моря. Число с проверкой по полю есть только на масштабе кадра или маршрута: мосты (TOCL 2026, ошибка суточного потока 1–41 %; RiSIM r = 0.91), пляжи с БПЛА (Martin 2021 — 0.12 ± 0.02 шт./м²), судовые камеры (ADIS).
2. Поправка на пропуски везде устроена одинаково. Чувствительность детектора измеряют на подвыборке, размеченной человеком, и делят на неё выход модели (Martin 2021: чувствительность 59 ± 3 %). Типичная чувствительность — 51–67 % (Takaya 2022, Fallati 2019). Человек по снимку тоже ошибается: ±43 % на квадрате 1×1 м (Can Gio 2026), а в зарослях гиацинта недосчёт по снимку ×14 (iScience 2026).
3. Высокий mAP не означает точного числа. При mAP50 0.99 на линии счёта в видео найдено только 6 предметов из 32 (Sensors 2025). Поэтому число нужно мерить отдельно, как у нас в L109.
4. Перенос на новое место плохой без дообучения: precision падает с ≈ 50 % до ≈ 20 % (van Lieshout 2020). Помогают 40–130 размеченных кадров нового места (TOCL 2026) или самообучение на неразмеченных кадрах (+12.7 AP, Jia 2024).
5. GSD: для учёта нужно 0.5–1.25 см/пикс (Andriolo 2023). Сегментация пластика лучше всего работает на 4 мм (Jakovljevic 2020). Слияние S2 с WorldView выявляет мишень от 0.6 × 0.6 м. На S2 пластик обнаружим при доле покрытия ≥ 20 % (PLP2021), это согласуется с нашим порогом ≥ 25 %. Радар в бассейне видит мусор от 1 шт./м², то есть от 10⁶ шт./км².
6. Счёт по карте плотности (CSRNet, DM-Count, P2PNet, FamNet) к плавающему мусору с проверкой никто не применял. Нужны точечные метки, поэтому этот путь оставлен для развития. VLM на плотном мусоре пропускают больше 3/4 предметов (WADE 2026).
7. Синтетика с внешним реальным тестом для плавающего мусора не найдена. «Чистый берег» (RU, Habr) взял 451 тыс. кадров StarGAN, получил mIoU 0.489, внешнего теста нет, у кода нет LICENSE. SR-GAN для S2 (2026) не описывает GT — не брать.
8. RU-источники: лидар МГУ с поправкой K ≈ 55 для шт./км² (Чёрное море), YOLOv8 по ТБО с БПЛА (Алматы), «Чистый берег». Курсовых и ВКР по плавающему мусору с кодом не найдено.
9. Готового к демо до 12:00 ничего нет, всё ниже — путь развития. Самое дешёвое — поправка на пропуски по отложенной подвыборке (строки M19, M21; предложение Э1).

## Предложения экспериментов (путь развития; до 12:00 в продукт не входят — сообщение оркестратора о возобновлении, 08:22)
- **Э1. Поправка на пропуски счётчика L109 по отложенной подвыборке (≈ 20 мин, без GPU, по уже сохранённым предсказаниям `cross_eval`).** На TUD-GV (60 кадров, недосчёт) случайно, seed 0, делим кадры 30/30. На первой половине считаем k = Σразметка / Σмодель, на второй применяем N·k.
  - **Правило, записанное заранее:** поправку принимаем, только если на второй половине MAE падает И 95 % бутстреп-интервал k не содержит 1. Иначе пишем «поправка не переносится».
  - На FML поправку не применять: смещение там уже −0.05.
  - Источник метода: M19 (Martin 2021), M21.
- **Э2. Дообучение на 40–130 кадрах нового домена (≈ 40 мин GPU).** По образцу M01/M02 на Maharjan (дрон, GSD 0.82 см) или TUD-GV: 50 % кадров на дообучение, 50 % на тест, разбиение по серии.
  - **Правило:** принимаем, если MAE на тесте ниже бейзлайна-медианы (Maharjan 0.93, TUD-GV 1.83) и mAP ≥ 0.3. Иначе «домен не освоен».
