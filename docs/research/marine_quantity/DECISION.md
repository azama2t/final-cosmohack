## 8. Готовый ответ жюри: «Как ваша система получает количество мусора в штуках на км²?»
> Штуки на км² мы получаем из полевых наблюдений, а не со спутника. Для каждого события C = N / A: N — посчитанные предметы, A — обследованная площадь (длина полосы × ширина). Интервал 95 % — точный пуассоновский. Пример — основной профиль (Саргассово море, визуальный учёт, > 2 см): 697 предметов на 12.94 км², то есть 53.9 [49.9–58.0] шт./км². Оценку для нового места мы проверили на отложенном участке маршрута против медианы: модель не лучше (MAE 30.0 против 25.2). Поэтому на карте показана медиана профиля с подписью «оценка по полевым данным».
> Sentinel-2 даёт зону скопления и её площадь в м² на км² воды, но не штуки. Мы проверили это на 21 053 реальных предметах ADIS: ни один не занимает 2×2 пикселя по 10 м. Пар «снимок → шт./км²» в открытых данных 0: 66 пар ADIS по месту и времени сигнала на снимке не дали, связь на уровне ячеек не подтвердилась. Поэтому штуки у спутниковой зоны — только сценарий с явными допущениями.
> Поштучный счёт по изображению у нас есть для фото с камеры у воды. Это отдельный модуль, он считает предметы на кадре. В шт./км² его результат переводится только при известной площади кадра.
> Путь к штукам со спутника — снимки 0.3 м по зонам Sentinel-2. Но на 0.3 м различима лишь четверть предметов, а волны и блики сами дают сотни ложных «предметов» на км². Нужен размеченный набор для проверки, открытого такого набора мы не нашли. Это следующий шаг, а не результат.

Пиксель к пикселю: r = 0.68 (B02), 0.90 (B03, B04, B08). Над водой SH систематически ниже на ≈ 0.0007 (B04 вода: 0.0005 против 0.0013) — сравнимо с порогами тёмной воды | то же |

**Решение (§24):**
- Текущий источник S2 (Earth Search `_0`) остаётся.
- Process API — только запасной канал для S2, S1 и Landsat. Переход на него — только по заранее записанному правилу: например, «метрики MARIDA test и срабатывания на 83 сценах зон при N0500 не хуже `_0` в пределах ДИ».
- ТОП-3 (раздел 4) и ответ жюри (раздел 8) **не меняются**: ключ CDSE не открывает VHR.
- Платный путь к VHR указан строкой в `INBOX_REQUESTS.md`; до защиты он не нужен.
