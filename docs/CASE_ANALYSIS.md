# Разбор кейса «Детектирование и оценка концентрации макропластика» и приоритеты решения

Источники: `task/postanovka.pdf`, `task/kriterii.pdf`, `task/README_macroplastic_dataset.md`, `task/macroplastic_marine_samples.csv`, `docs/CONTRACTS_V3.md`. Числа по CSV получены скриптом `scripts/case/eda_samples.py` (выход `reports/case_eda/`). Проверка архива снимков: зонд STAC по центроиду каждого из 318 событий, окно ±3 сут (Earth Search `sentinel-2-l1c`/`sentinel-2-l2a`, Planetary Computer `landsat-c2-l2`), сырой ответ в `out/case/probe_archive.json`. Полный реестр пар строит `scripts/case/find_pairs.py` (→ `data/pairs/`).

## Главное (5 выводов)

1. **Целевая величина фактически подсказана условием.** Контрольный пример «12 предметов на 0,20 км²» совпадает с профилем `S2_visual_GT2 / total_plastic`: полоса 10 м × ~20 км = 0,09–0,26 км² (медиана 0,23), N = 1–55 (медиана 8). Это 63 события, у всех есть N и A, и C = N/A воспроизводится до 4·10⁻¹² относительной ошибки. Предлагаем основную величину: **суммарный плавающий пластик, предметы > 2 см, шт./км², визуальный учёт с судна**.
2. **Пар «плотность пластика ↔ снимок» нет совсем.** Для S1 (Тихий океан, 181 событие) и S2 (Саргассово море, 63 события) в окне ±3 сут не нашлось ни одной сцены Sentinel-2 и почти ни одной Landsat (1 из 244): это открытый океан, и S2 до 27.06.2015 ещё не снимал. Сцены есть только для **общего мусора**: S4 (Чёрное море, 2024, 33 из 33 событий, 25 с облачностью < 30 % в ±3 сут) и S3 (Северное море, 2014, Landsat-8, 28 из 41, но на всех сценах облачность ≥ 30 %). Значит, перенос численной оценки на снимки подтвердить нельзя. На карте для зон статус «концентрация недоступна» или «исследовательская оценка» — ровно тот вариант, который предусматривает постановка.
3. **Отдельные предметы на снимке не видны физически.** Даже максимум реестра (2209 шт./км²) даёт 0,22 предмета на пиксель 10×10 м, медиана профиля > 2 см — 0,003. Детектор (LightGBM, MARIDA+MADOS, F1 MD test 0,871) работает на уровне скоплений и полос. Связь «пиксель → шт./км²» без пар не калибруется, а доля маски концентрацию не заменяет (Т3).
4. **Утечки и зависимость строк здесь главная ловушка.** В 13 полях лежит ответ или производное от него: `concentration_*`, `items_count`, `density_numerator_items`, `source_*_items`, `reported_*`, `parent_*`, `zero_scope`. У 120 из 181 события S1 несколько строк, а за один день проходит до 16 событий S1 и до 8 событий S4. Разбиение делаем по группам «день × район», не по `sample_id`.
5. **Баллы решают алгоритмы и честность, а не интерфейс.** О1+О2+Т1+Т3+Т4 = 62 из 105, и почти всё это закрывается кодом отбора, реестром пар, расчётом C = N/A с интервалом Пуассона и групповым сплитом. У интерфейса О4+Т5 = 8. Детектор (О3 10 + Т2 15) у нас почти готов.

### 1.2 Ограничения и правила

| Правило | Формулировка (суть) | Как соблюдаем |
|---|---|---|
| Масштаб | пиксели 10–30 м → уровень **вероятных скоплений**, не предметов | зоны = скопления; концентрация зоны только со статусом |
| 20 м → 10 м | при приведении каналов «исходная детализация сохраняется» (без сглаживания, ближайший сосед/без искусственной детализации) | в `stac.py`/`io.py` проверить метод ресэмплинга и записать в README |
| Пригодность ≠ класс | пригодность пикселя (облако/блик/суша/nodata) и принадлежность к классу проверяются **раздельно**; неразмеченные пиксели ≠ подтверждённый фон | маска качества отдельным слоем; метрики детектора только по размеченным пикселям (ignore=0) |
| Источник эталона | указывается отдельно от факта совпадения снимка с полевым наблюдением | в реестре пар поле `label_source` (MARIDA/поле/нет) |
| Совокупности | предмет, категория, общий мусор, суммарный пластик — разные величины | фильтр по `record_type`, `target_scope`, `measurement_profile` в конфиге |
| Нули и пропуски | пусто ≠ 0; ноль действует только в своём `zero_scope` | не заполнять NaN нулями; категории не суммировать (у S1 GT5 H/N/F разные наборы категорий на событие: N 78, H 52, H+N 14, F+H 4, F+N 2) |
| Время | дата без времени ≠ 00:00; конец < начала = переход через полночь (27 трансект S1) | сдвиг пары считать от интервала; при неизвестном времени (S4, аэросъёмка S1) — неопределённость ±12 ч |
| Геометрия | концентрация относится ко **всей обследованной площади**, а не к центральному пикселю; точка = середина полосы / наблюдатель | пара = полоса (линия start–end с буфером) ∩ сцена; для S4 только точка → буфер + пометка |
| Прерванные трансекты S2 | T18, T22, T35, T49: концы не описывают маршрут; сегменты из PANGAEA 931834 | для пар не использовать отрезок start–end; площадь — авторская итоговая |
| Общий мусор | средняя доля пластика из публикации не переносится на отдельное наблюдение | S3/S4 не смешивать с пластиком |
| Прогноз | отдельно от наблюдений, проверка без будущих данных | дрейф OpenDrift — только доп. функция О6 |
| Повтор | повторный запрос с теми же данными и настройками даёт тот же результат; реестр при повторном запуске согласован с данными | детерминизм, фиксированный seed, кеш сцен по scene_id |

### 1.3 Формулы

| Что | Формула | Контроль |
|---|---|---|
| Полевая концентрация | C = N / A, N — число предметов выбранной совокупности, A — обследованная площадь, км² | 12 / 0,20 = **60 шт./км²** |
| Ошибка | абсолютная ошибка = \|Ĉ − C\|; MAE = среднее по событиям | модель 75 на той же площади → **15 шт./км²** |
| Доля маски | 20 % пикселей — это доля площади зоны, не концентрация; переход к шт./км² требует калибровки | в UI площадь зоны и концентрация в разных полях |
| Неопределённость поля (предлагаем) | точный интервал Пуассона (Гарвуд) для N, делённый на A: [χ²(α/2; 2N)/2, χ²(1−α/2; 2N+2)/2] / A | для N = 12, A = 0,20: 95 % ДИ ≈ 31,0–104,8 шт./км²; при медиане S2 N = 8 интервал −57…+97 % |
| Площадь полосы | A = L × W (S2: W = 10 м, L ≈ 20 км → 0,2 км²); для S2 авторская площадь заменяет расстояние между концами | 20,5 км × 10 м = 0,205 км² |
| Масса | г/км² — только дополнительный результат при калибровке (есть только в S1) | не основной |
| Спутниковое C | всегда «модельная оценка», визуально отличается от измерения | статусы и значки |

### 1.4 Разбиение и проверка: что считается ошибкой или утечкой

| Нарушение | Почему это ошибка | Правило |
|---|---|---|
| Строки одного `event_id` в train и test | категории и объекты одного события — одно измерение | группа ≥ event_id |
| Разные события одного дня и района в train и test | одна сцена, одно море, одна погода; S1 до 16 событий/день | группа «дата × район (ячейка ~1°)», для S2/S1 — блоки по дням рейса |
| Одна сцена в train и test (детектор) | пиксели одной сцены коррелированы | групповой сплит по сцене (как в MARIDA) |
| Подбор порога/гиперпараметров по test | подгонка под ответ | порог по val; test считается один раз (`final_test.py` уже запрещает повтор) |
| Признаки из ответа | `concentration_*`, `items_count`, `density_numerator_items`, `source_object_filtered_items`, `reported_*`, `parent_*` | whitelist признаков в конфиге + тест, что leak-поля не попадают в X |
| Признаки, недоступные при применении | `sea_state_beaufort`, `wind_speed_kn` есть только у S1 (72 %), у визуальных трансект их нет | для спутникового сценария брать ветер из реанализа (ERA5/GFS) по дате-месту, а не из CSV |
| MAPE как основная метрика | есть нули (38 строк) | MAE + RMSE (+ MAE в лог-пространстве как доп.) |
| Сравнение разных профилей | размер, метод и совокупность должны совпадать | модель и бейзлайн на одном профиле и одном сплите |
| «Концентрация = площадь маски × k» без пар | калибровка не подтверждена | статус «исследовательская оценка» с допущениями или «концентрация недоступна» |

### 3.5 Поля-утечки: не признаки

| Поле | Почему нельзя |
|---|---|
| `concentration_items_km2` | это ответ |
| `concentration_g_km2` | масса по тем же предметам и той же площади (S1); у лёгкой массы и счёта общая выборка |
| `concentration_value_orig`, `concentration_unit_orig` | тот же ответ в исходных единицах |
| `items_count` | N текущей категории/объекта; при известной A даёт C = N/A напрямую |
| `density_numerator_items` | прямо числитель C = N/A |
| `source_object_filtered_items`, `source_reported_total_items` | отфильтрованный/суммарный счёт предметов события (у S1 аэро — плотность × площадь, т.е. сам ответ) |
| `reported_concentration_items_km2`, `reported_concentration_g_km2` | справочные значения той же концентрации |
| `parent_concentration_items_km2` | плотность родительского события, для строки категории — ответ «соседа» из того же события |

| `zero_scope` | заполнен только при C = 0 — индикатор ответа |

### 4.3 Разрешение против размера предметов

| Профиль | Мин. размер | Предметов на пиксель 10 м: медиана / максимум |
|---|---|---|
| S2_visual_GT2 | 2 см | 0,003 / 0,022 |
| S3_visual_GT2 | 2 см | 0,0008 / 0,020 |
| S4_visual_GT2_5 | 2,5 см | 0,022 / 0,098 |
| S1_trawl_5_to_50 | 5 см | 0,063 / 0,22 |
| S1_aerial_GT50 | 50 см | 0,00004 / 0,0005 |

Предмет 2 см занимает 4·10⁻⁶ площади пикселя 10 м. Отдельный макромусор на снимке не виден. Видны только плотные скопления, полосы и фронты (windrows), где мусор собирается вместе с водорослями и пеной. Полоса наблюдения S2 шириной 10 м — это один пиксель по ширине.

Как подавать:

1. Детектор отвечает на вопрос «есть ли на снимке признаки **скопления**» (зона, маска, вероятность). Метрики — по разметке MARIDA, а не по полю.
2. Концентрация шт./км² — измерение на поле (C = N/A с интервалом Пуассона) и модель по полевым данным: пространственно-временной прогноз, проверенный на групповом сплите.
3. Связь «снимок → шт./км²» — отдельный исследовательский эксперимент на парах S4/S3 (общий мусор): есть ли монотонная связь доли маски или FDI в полосе с плотностью (Спирмен, бутстреп-ДИ). Ожидаем слабую связь. Отрицательный результат тоже вывод, и он прямо разрешён постановкой («допускается раздельная проверка детектора и количественной модели»).
4. На карте: у измерения статус и интервал, у зоны — площадь и статус «концентрация недоступна» (пар нет) или «исследовательская оценка» (с допущениями и ссылкой на эксперимент 3).

### 5.4 Чего НЕ делать (штрафуют критерии)

- Не смешивать S3/S4 (общий мусор) и категории с суммарным пластиком. Не суммировать категории S1 при пропусках. Не подставлять 0 вместо пусто.
- Не выдавать долю маски, FDI или «индекс ‰» за концентрацию. Шт./км² на снимке — только со статусом и калибровкой.
- Не брать признаки из утечных полей и из `sea_state` для спутникового сценария. Не делить сплит по строкам.
- Не подбирать порог и гиперпараметры по test. Не пересчитывать test несколько раз.
- Не заявлять перенос на снимки без пар. Для пластика пар 0 — так и пишем.
- Не использовать MAPE как основную метрику (нули).
- Не тратить часы на оформление: у интерфейса 8 баллов из 105.
- Не показывать прогноз дрейфа как наблюдение.
