# DECISIONS — ключевые решения

| Решение | Альтернативы | Почему |
|---|---|---|
| Показатель — доля наблюдаемой воды с признаками мусора (‰) в ячейке H3 res 8 | площадь/масса пластика | разметка MARIDA частичная, физическую концентрацию по снимку не измерить честно |
| Главная модель — пиксельный LightGBM на каналах+индексах | UNet | в статье MARIDA RF+индексы (F1 0.80) сильнее U-Net (0.50); бустинг быстрый; UNet проверяется отдельно |
| Живое демо — marinedebrisdetector на L2A + наша модель вторым слоем | только наша модель | MDD обучен на L2A, наша — на ACOLITE rhorc (сдвиг домена) |
| Фронт — Vite+React+MapLibre+deck.gl+ECharts | Leaflet | 3D-гексагоны, анимация треков, WebGL-скорость |
| Слои моделей — `<region>/<date>/<model>/` | суффиксы в именах | переключатель моделей без переименований |
| Регионы живого демо: Гондурасский залив, Гаити (Порт-о-Пренс), + третий по наличию безоблачной сцены | все регионы MARIDA | больше всего размеченного мусора в MARIDA; остальные регионы — после основной ступени |
| Итоговая модель MARIDA — бинарный LightGBM с оконными признаками, порог 0.37 по val | мультикласс, UNet | лучшая на val (0.906±0.003), 2.8 МБ, 0.1 с на патч |
| Слой «наша модель» на живых L2A — вариант с L2A-аугментацией + гармонизация по медиане воды (SCL=6) | итоговые веса без гармонизации | на совпадающей сцене Дурбан 24.04.2019 (L2A vs ACOLITE) находит 36/46 размеченных px против 26/46, +1 FP; на val не хуже (0.911) |
| Акцент находок — коралловый `#ff6b4a`, подложка по умолчанию — тёмная CARTO; сравнение — split-screen | шторка | районы разные, у них разная геометрия |
| MDD: чекпойнт unet++1 epoch=54, порог показа 0.5 (порог чекпойнта 0.0639 сохранён в json) | порог чекпойнта | с порогом 0.0639 на бликовой сцене 40 ‰ воды помечено; сверка с предсказанием авторов по Дурбану r = 0.886 (другие эпохи 0.62–0.64) |
| Источник пикселей: Planetary Computer для сцен ≥ 2022, Earth Search до 2022 | только Earth Search | ES обрезает тёмную воду до DN=1 и дублирует offset в метаданных |
| Маска воды: SCL 6 + (SCL 2/7 и NDWI > 0), минус 2 px у суши и 5 px у облаков/теней; бликовые сцены отбрасываются | только SCL 6 | краевые и бликовые ложные срабатывания |
| Демо-тур и скриншоты — по району с наибольшим числом находок на последней дате; шаги без данных пропускаются | фиксированный район | тур всегда показывает непустую картину |
| UNet и стек в финал не взяты | стек (+0.010) | прирост меньше 2×шума UNet; вес смеси подобран на той же val |
| Итоговая модель — LightGBM на MARIDA train + MADOS (порог 0.63), сцены MADOS, совпадающие со снимками val MARIDA (13), исключены | только MARIDA | +0.017 F1 на val (0.906 → 0.923), проходит правило принятия; проверено, что обучающие сцены MADOS не совпадают со снимками test MARIDA |
| Слой «наша модель» на живых L2A оставлен на `weights/lgbm_live` | новая модель | на совпадающей сцене L2A новая модель без гармонизации находит меньше (24/46) |
| Пиксель → ячейка H3 через растеризацию границ ячеек в UTM | latlng_to_cell на каждый пиксель | 0.2 с вместо ~10 с на 2500², расхождение только на границах |
| Флаг качества даты (блик/дымка: B11 воды > 0.01 или B8 воды > 0.006); по умолчанию показывается последняя дата без флага | показывать всё одинаково | дымка завышает срабатывания MDD; пользователь видит пометку |
| Дрейф: OpenDrift OceanDrift, HYCOM ESPC-D-V02 + NCEP GFS, коэффициент ветра 0.02 + ансамбль 0.01/0.03; только свежие сцены 2025–2026 | ERA5/Copernicus Marine | без аккаунтов; ретро-дрейф без проверенного архива не делаем; подпись «демонстрационный прогноз, без валидации» |
| Лучший район для тура — максимум находок среди районов, у которых свежая сцена без флага дымки/блика | буквальный максимум | иначе тур показывает дымку (Джакарта) |
| «Уверенные находки» = согласие двух моделей в радиусе 20 м; переключатель в UI, по умолчанию показываются все | только консенсус | консенсус остаётся лишь в 15 из 29 сцен; подпись «согласие моделей, не проверка на месте» |
| Главная метрика в отчёте — F1 MD val 0.923 с CI по сценам [0.877; 0.970] и честной оценкой на новом регионе 0.854 (leave-region-out) | только val ± seed | seed-разброс занижает неопределённость; жюри спросит про перенос |
| Кнопка «Дообучить» решает по правилу на val MARIDA и не подменяет веса | автоподмена | метки L2A почти не влияют на val ACOLITE; честный отказ лучше тихой подмены |
| Загрузчик датасета: 3 формата (суффиксы масок, images/masks, CSV чип→класс), неизвестное — в «Сомнения», а не угадывание | один формат | формат организаторов неизвестен |
| Инференс LightGBM на GPU — своё CUDA-ядро леса (NVRTC), откат на CPU с предупреждением | LightGBM GPU-сборка, torch | 300 чипов холодным стартом: 5.7 с (GPU) / 21 с (CPU) против 45 / 40 с; бит в бит; без новых пакетов |
| Основная модель не заменена лёгкой | лёгкая (в 3 раза быстрее на CPU) | не прошла leave-region-out (0.824 против 0.854) |
| Буфер от облаков 5 px + спектральная маска и тест тени | буфер 10–20 px | буфер 20 px убрал бы 13 уверенных находок; настоящие ошибки — пропущенные SCL облака и тени |
| Демо-набор для чистого клона: 5 районов с дрейфом, 17 МБ | 2 района | жюри в чистом клоне видит больше реальных данных |
| Обзор по умолчанию — 3D-глобус (60 fps на RTX 4070), переключатель на карту | только плоская карта | нагляднее для 12 районов по миру; без аппаратного WebGL — карта |
| «Порядок посещения зон» — жадный ближайший сосед от ближайшего порта, км по прямой, подпись «черновой порядок, не навигационный маршрут» | оптимальный маршрут | честная черновая оценка без навигационных данных |
| Основная модель остаётся (48 признаков); скорость на CPU — ограничение, честно записано: 300 чипов ≈ 22 с на 20 потоках, ≈ 38 с на 8, ≈ 80 с на 4; с NVIDIA — 5.7 с | лёгкие модели | лёгкая хуже переносится (LRO −0.03), средняя почти не быстрее |
| Порог смещения L2A в `--scale auto` — 500 DN (медиана B12 тёмных пикселей) | 1000 DN | со смещением минимум по 48 сценам 1005 DN — у 1000 запаса нет; без смещения вода 10–240 DN |
| Завтра: порог подбирать под метрику организаторов (по всем пикселям или по размеченным), классы вроде sea snot — в негативы, если у них они «прочее» | порог 0.63 с val MARIDA | репетиция: по всем пикселям лучший порог ≈ 0.999, при 0.63 F1 0.058; по размеченным без sea snot — 0.945 |
| Районы вне MARIDA — у устьев рек из списков крупнейших источников выноса пластика (источники в отчёте; непроверенные ссылки помечены) | случайные побережья | показ на реальных «горячих точках»; сцены на мутной воде у дельт отбрасываются как ложные |
| Артефакты (шов детекторов, кильватер, судно) помечаются `artifact` и исключаются из индекса, зон, таймсерий и «уверенных»; на карте — приглушённо по переключателю | удалять | прозрачность: видно, что и почему исключено |
| Балл зоны = базовый × (1 + доля подтверждённых пикселей) × 0.5 при дымке/блике; повторяемость — только по надёжным датам | прежняя формула | приоритет — там, где модели согласны и снимок надёжен |
| Демо-набор — топ-3 рейтинга по надёжным датам (Нил, Гуанабара, Мумбаи), все с дрейфом, 12.8 МБ | 5 районов | жюри в клоне видит лидеров рейтинга |
| Кильватер «судно в торце»: вытянутый объект ≥ 200 м + яркая цель в ≤ 5 px от торца, B4/B3 ≥ 0.6 | только длинные прямые полосы | в Мумбаи кильватеры были 401–462 м, лодки чуть темнее порога; проверено глазом на всех 5 срабатываниях |
| Установка без NVIDIA — `requirements-cpu.txt` / `run.ps1 -Cpu` (выбирается сам без nvidia-smi) | только CUDA | у жюри может не быть NVIDIA; CUDA-venv ≈ 5.7 ГБ |
| Артефакт одной модели переносится на пересекающийся объект другой (`artifact_from`); пиксели артефактов не подтверждают «уверенные находки»; коллинеарные куски с зазором ≤ 3–5 px проверяются как одна полоса | правила по моделям отдельно | зона №1 LightGBM в Мумбаи стояла на кильватере, подтверждённом маской MDD |
| Подложки только онлайн (CARTO/Esri) с атрибуцией; офлайн — наши снимки Sentinel-2 + береговая линия Natural Earth | локальный кэш тайлов CARTO/Esri | условия CARTO запрещают массовую загрузку и серверное кэширование, Esri требует свой офлайн-экспорт; начатая загрузка остановлена и удалена |
| Без численных «угроз через N часов», алертов и метки «постоянный источник»; пересечение демо-дрейфа с объектами OSM — только в панели дрейфа с подписью «демо-прогноз, не валидирован» | алерты в ленте | прогноз дрейфа не валидирован (проверка: не лучше базовой линии) |
| «Подтверждено» — только действие человека во вкладке «Проверка»; согласие моделей — сигнал | согласие = подтверждение | честность статусов |
| Интерфейс v2 по умолчанию (`service/static_v2`), откат — `MACROPLASTIC_UI=v1` | оставить v1 | v2 прошёл смоук 17/17 и офлайн 16/16 без ошибок консоли, контраст WCAG 0 нарушений, тест понятности (4 задачи за 1–3 шага), ручную проверку на реальных и «организаторских» данных |
