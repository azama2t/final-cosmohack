# DECISIONS — ключевые решения

| Решение | Альтернативы | Почему |
|---|---|---|
| Показатель — доля наблюдаемой воды с признаками мусора (‰) в ячейке H3 res 8 | площадь/масса пластика | разметка MARIDA частичная, физическую концентрацию по снимку не измерить честно |
| Главная модель — пиксельный LightGBM на каналах+индексах | UNet | в статье MARIDA RF+индексы (F1 0.80) сильнее U-Net (0.50); бустинг быстрый; UNet проверяется отдельно |
| Живое демо — marinedebrisdetector на L2A + наша модель вторым слоем | только наша модель | MDD обучен на L2A, наша — на ACOLITE rhorc (сдвиг домена) |
| Фронт — Vite+React+MapLibre+deck.gl+ECharts | Leaflet | 3D-гексагоны, анимация треков, WebGL-скорость |
| Слои моделей — `<region>/<date>/<model>/` | суффиксы в именах | переключатель моделей без переименований |
| Регионы живого демо: Гондурасский залив, Гаити (Порт-о-Пренс), + третий по наличию безоблачной сцены | все регионы MARIDA | больше всего размеченного мусора в MARIDA; остальные регионы — после основной ступени |
| Итоговая модель MARIDA — бинарный LightGBM с оконными признаками, порог 0.37 по val | мультикласс, UNet | лучшая на val (0.906±0.003), 2.8 МБ, 0.1 с на патч |
| Слой «наша модель» на живых L2A — вариант с L2A-аугментацией + гармонизация по медиане воды (SCL=6) | итоговые веса без гармонизации | на совпадающей сцене Дурбан 24.04.2019 (L2A vs ACOLITE) находит 36/46 размеченных px против 26/46, +1 FP; на val не хуже (0.911) |
