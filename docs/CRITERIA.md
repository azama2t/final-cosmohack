| Локальная метрика | `scripts/tools/score.py` | секунды |

Риски private metric (обновлено):
1. **Метрика по всем пикселям при частичной разметке** — главный урок репетиции: при пороге 0.63 F1 0.058, лучший порог ≈ 0.999 (F1 0.25), обучение на их train — 0.317. Порог подбирается под их метрику (`--metric-zero`).
2. **Другое определение негатива** (у них «прочее» = слизь, нефть): добавить в негативы; заготовлен вариант модели с такими негативами.
3. **Сдвиг домена** ACOLITE → их обработка: LRO 0.854 против val 0.923; смягчение — обучение на их train за минуты.
4. **Смещение L2A +1000 DN** — закрыто авто-детекцией (порог 500 DN), но проверить долю пропусков по каналам в отчёте загрузчика.
5. **CV на их train ранжирует варианты не так, как скрытая разметка** (дважды): выбор по правилу, записанному в `TOMORROW.md`, а не по CV.
6. **Скорость на их CPU** — см. строку «Скорость».
7. Утечка из MARIDA/MADOS, если их test — те же сцены: `provenance_check.py`.
