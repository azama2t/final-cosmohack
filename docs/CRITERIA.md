## Private metric (40): как мы готовы

Данных организаторов нет. Готовность — инструменты и скорость цикла «данные → первый сабмит».

| Звено | Что есть | Время |
|---|---|---|
| Разбор незнакомого архива | `python -m macroplastic.ingest <архив>` (безопасная распаковка, 3 формата, HTML «Сомнения»), `scripts/tools/inspect_dataset.py` | 5–10 мин |
| Выводимость разметки из спектра | `scripts/tools/label_forensics.py` (деревья 3/4/5, LightGBM, пороги индексов, групповой сплит) | 10 мин |
| Приведение к нашему формату | `scripts/tools/adapter.py --config configs/adapter_*.yaml` (каналы, масштаб, offset, классы) | 10–15 мин |
| Пересечения с MARIDA/MADOS | `scripts/tools/provenance_check.py` (тайл+дата, bbox, SHA-1, pHash) | 5 мин |
| Переобучение | LightGBM: 4.5 с обучение (MARIDA+MADOS 363 тыс. px), кэш признаков; лёгкие модели L23 — 1–2 с; `scripts/train_lgbm_ingest.py` | минуты, 3 seed < 1 мин |
| Сабмит | `inference.py` → prob/mask GeoTIFF, коды 0/1/2 | секунды |
| План часа | `TOMORROW.md`, `docs/TOOLS.md` | — |

Риски private metric:
1. **Масштаб L2A с offset +1000** (baseline ≥ 04.00): авто-масштаб умножает на 1e-4, но не вычитает 0.1 → находки исчезают молча (`robustness.md`, случай 6). Если данные организаторов — L2A DN, первый сабмит будет ≈ 0. Защита: адаптер умеет `radiometry.offset`, но `inference.py --scale auto` — нет. **Главный риск.**
2. **Сдвиг домена** ACOLITE (MARIDA) → их обработка: leave-region-out уже показывает падение 0.923 → 0.854; на чужой атмосферной коррекции — хуже. Смягчение: переобучение на их train за минуты, гармонизация по медиане воды.
3. **Метрика другого вида** (по объектам / по патчам / IoU по всем пикселям, а не по размеченным): порог надо подбирать под их метрику, у нас подбор по F1 размеченных пикселей. Смягчение: порог — параметр, `label_forensics` + их val.
4. **Маленькие или нестандартные чипы** (< 16 px, другой набор каналов): падение с IndexError / exit 2. Смягчение: паддинг, `bands.missing: nan`.
5. **Классы**: если «макропластик» у них — несколько классов или включает пену/Sargassum, бинарная модель «MD против всего» не подходит без переобучения (схема MARIDA 15 классов у нас есть).
6. **Скорость на их проверке** — см. строку «Скорость» (CPU на 4–8 потоках > 30 с).
7. Утечка из MARIDA/MADOS, если их test — те же сцены: val-оценка завысится; `provenance_check.py` покажет, решение — в DECISIONS.md.
