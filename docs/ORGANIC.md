# Органика отдельно (INBOX §51 п.9, замечание эксперта п.4) — L143

## 1. Что умеет рабочий детектор

- `weights/lgbm/model.txt`: `objective=binary`, `num_class=1`; `weights/lgbm/meta.json`: `task: binary`, `classes: [0, 1]`,
  `md_class: 1`. Выход — одна вероятность «MARIDA Marine Debris / нет».
- Классы MARIDA Dense Sargassum (2), Sparse Sargassum (3), Natural Organic Material (4) в обучении — **фон (класс 0)**,
  отдельного класса «органика» у модели нет. Код зон (`scripts/case/scene_zones.py`) берёт только `prob.tif`/`det.tif`.
- Итог: **органика отдельно не выделяется моделью.** Модель обучена *не* путать органику с мусором, но различать её
  как отдельный класс не может.
- Сколько органики модель всё же называет мусором (MARIDA val, из `weights/lgbm/meta.json`, `val_per_class_pred_md`;
  порог 0,63 выбран на этом же val — оценка оптимистичная):

| класс MARIDA | пикселей val | названо мусором | доля |
|---|---:|---:|---:|
| Marine Debris | 1075 | 984 | 91,5 % |
| Dense Sargassum | 1167 | 0 | 0 % |
| Sparse Sargassum | 385 | 6 | 1,6 % |
| Natural Organic Material | 92 | 53 | **57,6 %** |

Главный риск — не саргассум, а «прочая природная органика» (древесина, растительные остатки): больше половины её пикселей
val детектор считает мусором.

## 2. Спектральный флаг «вероятно органика» — ЭКСПЕРИМЕНТ (правило записано ДО расчёта, 26.09 18:35)

Правило (для пикселя; для зоны — медианы по пикселям детекции зоны):

    likely_organic = (NDVI ≥ 0,20) и (FAI > 0)
    NDVI = (B8 − B4) / (B8 + B4);  FAI = B8 − [B4 + (B11 − B4)·(833 − 665)/(1614 − 665)]   (src/macroplastic/indices.py)

Источники и обоснование порогов:
- FAI > 0 — Hu C. (2009) *A novel ocean color index to detect floating algae in the global oceans*, Remote Sensing of
  Environment 113: 2118–2129: плавающая растительность даёт положительную аномалию NIR над линейной базой red–SWIR;
  вода — около нуля или ниже. Сам по себе FAI > 0 выполняется и для плавающего мусора — это условие «плавает», а не «органика».
- NDVI ≥ 0,20 — разделяющее условие. Biermann L. et al. (2020) *Finding plastic patches in coastal waters using optical
  satellite data*, Scientific Reports 10: 5364: в пространстве FDI–NDVI водоросли (seaweed) лежат выше по NDVI, чем
  пластик. Число 0,2 — **приближённая граница, снятая с рисунка**, и одновременно общепринятая нижняя граница растительного
  отклика NDVI; в таблицах статьи отдельного порога нет. Порог **не подбирался** на MARIDA.
- Спектры классов MARIDA (Kikaki et al. 2022, PLoS ONE 17(1): e0262247): у Sargassum и природной органики — выраженный
  красный край/пик NIR (хлорофилл), у мусора — более плоский спектр.

Проверка: MARIDA **val** (не test), все размеченные пиксели классов 1–4, доля флага по классам; дополнительно — только
среди пикселей, которые детектор назвал мусором (P ≥ 0,63). Чувствительность к порогу NDVI (0,1 / 0,3) — только для
справки, основным остаётся 0,20.

Ограничения (заранее): MARIDA — ACOLITE rhorc, сцены сервиса — L2A; NDVI смешанного пикселя (мусор + вода) ниже, чем
у чистого материала; флаг не классификатор, на test не проверялся.

Выводы:
1. Флаг почти не задевает мусор (1 из 418 объектов val) и надёжно отмечает саргассум (плотный 16/16, редкий 42/60).
2. **Но саргассум детектор и так не путает с мусором** (0/1167 и 6/385), а путает «прочую природную органику»

   в «Не проверяется».
4. Сцен мало (саргассум — 3 сцены val, NOM — 5), пиксели внутри сцены зависимы — доли ориентировочные.

## 4. Зоны сервиса (`scripts/case/organic_flag.py zones`)

Для каждой сцены `data/case/scene_zones/<key>/` кластеры детекции пересобраны тем же правилом, что в
`scripts/case/scene_zones.py` (дилатация 150 м, ≥ 5 пикс.), идентификаторы зон совпали во всех 79 сценах с зонами
(4 сцены Дурбана без зон — не оцениваются, пропущены). Итог (`reports/organic/zones_flag.json`): 83 сцены, 255 зон,
**флаг у 2**: `SZ-live-manila-2019-05-13-008` (NDVI 0,25, 9 пикс.), `SZ-live-santo_domingo-2025-12-30-001` (NDVI 0,35,
5 пикс.). Медиана NDVI зон −0,016 (p90 0,063). Обе помеченные зоны — «обнаружено» и считаются находками (2 из 77): флаг статус не меняет, в карточке — строка «Органика: вероятно органика … эксперимент». Файлы: `data/case/scene_zones/<key>/organic.json`.

## 5. Поля API (для фронта)

`/api/v3/scene_zones` и выгрузки (GeoJSON — все свойства; CSV — колонки `likely_organic`, `organic_ndvi_median`,
`organic_fai_median`, `organic_label`):
- `properties.likely_organic` — true | false | null (null — флаг не посчитан, например зона «не обнаружено»);
- `properties.organic` — `{likely_organic, ndvi_median, fai_median, organic_px_share, n_px, label, experiment: true,
  experiment_label: "эксперимент", rule, sources, model_note: "органика отдельно не выделяется моделью (…)", validation, doc}`;
- `label` — готовая строка «Органика: …» для карточки;
- `classification.not_checked_label` — где флаг посчитан: «Не проверяется: древесина и прочая органика (модель органику
  отдельно не выделяет)»; `classification.organic_label` = `organic.label`;
- фильтр: `/api/v3/scene_zones?organic=true|false` (и `/api/v3/export?layer=scene_zones&organic=…`).
Статус зоны флаг **не меняет** (эксперимент; число находок прежнее).
