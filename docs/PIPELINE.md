# PIPELINE — как мы искали данные и пришли к алгоритму (хронология попыток, включая неудачи)

Формат каждой строки: **что пробовали → число → решение → почему → файл-доказательство**. Отрицательные результаты оставлены: именно они определили форму продукта.
Время — по коммиту (`git log --reverse --format="%h %ad %s" --date=format:"%d.%m %H:%M"`), без коммита — по отчёту. Главные числа — из `reports/final_numbers.json` (раздел `case`). Статусы: **принято**, **отклонено**, **бейзлайн**, **справочно**, **в работе**.
Вход в репозиторий — `docs/INDEX.md`; журнал поиска данных по строкам — `docs/SEARCH_LOG.md`.

![Воронка данных](img/funnel.png)

*Воронка: `docs/img/funnel.png`, генератор `docs/img/funnel_fig.py` (числа — из `data/pairs/*`, `reports/search/*_candidates.csv`, `reports/search/search_numbers.json`, `reports/extra_data/*`; сводка — `docs/img/funnel.json`).*

**Главный количественный результат — полевой алгоритм шт./км²** (C = N/A с интервалом Пуассона; на отложенном участке маршрута модели сравнены с медианой, разделы 3 и C8). **Перенос на снимки мы не заявляем как результат:** пары «снимок ↔ поле», PLP, ячейки — это воспроизводимые **проверки** с их итогом (разделы 4, 6, 8); спутниковое количество у зоны — только **сценарий** с допущениями.

**Маршрут продукта:** CSV наблюдений → отбор записей по профилю → пары «наблюдение ↔ снимок» → маски качества в полосе → детектор (LightGBM) → карта: полевые измерения (C = N/A с ДИ Пуассона), полосы-кандидаты, подозрительные пиксели; оценка по полю = медиана профиля.
**Проверки отдельно от продукта:** детектор — на отложенном test MARIDA; оценка по полю — CV по участкам маршрута и отложенный test; связь «снимок ↔ поле» — исследовательский эксперимент на парах.

## Итог в семи строках

1. **Детектор.** Пиксельный LightGBM с оконными признаками на MARIDA + MADOS: F1 val 0.923, **test MARIDA 0.871 [0.823–0.920]** (посчитан один раз; RF 0.771, FDI×NDVI 0.042). UNet, стек, лёгкая и средняя модели отклонены по заранее записанному правилу.
2. **Синхронизация.** 318 событий → 68 со снимком в ±5 сут → 29 по метаданным → 12 прошли маски качества → **0 синхронных** при типичном дрейфе (0.2 м/с, допуск 3 км). Для пластика (S1 GPGP, S2 Саргассы) снимков Sentinel-2 нет вовсе.
3. **Концентрация по полю.** C = N/A (контроль 12 / 0.20 км² = 60). Выигрыш kNN над медианой оказался **утечкой маршрута**. На отложенном test модели **не лучше медианы** (S2 30.0 против 25.2) → на карте медиана профиля.
4. **Детектор на снимках пар.** С гармонизацией — 975 объектов на 22 вырезках; визуально **≈ 98 % — фон** (вероятных скоплений 1.7 %). Гармонизация хуже на MARIDA val (0.897 против 0.923) → **выключена**; без неё 5 объектов, 0 в полосах.
5. **Снимок ↔ поле.** Эксперимент на 11 парах (весь мусор, all_litter) — **связь не установлена** (знак обратный, при 6 группах обнаружима только |ρ| ≥ 0.96). Калибровку «снимок → шт./км²» не делали.
6. **Расследование данных (26.09).** События CSV: A 0 · C 9 → розыск закрыт по стоп-правилу. Найденный нами ADIS: 21 444 отрезка → **66 пар по месту и времени** (уровень A; не калибровочные). На 6 синхронных отрезках ADIS с единичными предметами детектор предметы не увидел (оценивается на 3 из 6 — на всех 0); это согласуется с физикой (доля покрытия ~10⁻⁷), но не задаёт общий предел для всех скоплений. **Калибровочных пар «снимок → шт./км²» — 0.** Новые B: 65 съёмок + 14 374 окна Cózar; D: 2 094 судна, 28 сцен облаков. Детектор v2: ни один вариант не прошёл заранее записанное правило → weights/lgbm (раздел 7). Раздел 6.

7. **Независимая проверка (член команды, без наших результатов).** PLP2019: «спектр → доля покрытия пластиком» не подтверждён (ρ(FDI) = 0.09, модель ≈ предсказание средним) → штуки у спутниковой зоны — только сценарий. Ruiz 2020 — D. FML — штуки на кадр без площади. Раздел 8.

## 6. Расследование данных (26.09, с 00:45; обновлено 05:40)

Детектор — только на B + проверенных D; «снимок → шт./км²» — только на A. Построчный журнал — `docs/SEARCH_LOG.md`.

## Чего мы сознательно не делали

- Не называли all_litter (S3, S4) пластиком. Не выдавали шт./км² по снимку без подтверждённой калибровки: пары ADIS — «по месту и времени», калибровочных пар 0; диапазон шт./км² у спутниковой зоны — только сценарий с допущением, не интервал и не измерение.
- Не подбирали модель после открытия test (ни детектора, ни концентрации).
- Не считали снимок в окне ±1/±3 сут парой без оценки дрейфа; дрейф — область розыска, не доказательство.
- Не превращали кандидатов (C) в положительные метки автоматически.
