Генерируется `scripts/render_docs.py` из `reports/final_numbers.json` (`case.sections.quantity`, `adis_pairs`, `field_test`); руками не править.
Исходные расчёты — `reports/quantity/*.json` (`scripts/case/quantity_report.py`, `quantity_live.py`; код `src/macroplastic/case/coverage.py`, `concentration.py`), пары ADIS — `reports/search/adis_candidates.csv`.

## 0. Единая логика: три уровня связи «снимок ↔ полевое число»

| Уровень связи | Сколько | Что это значит |
|---|---:|---|
| Пара по месту и времени (уровень A, ADIS) | **66** (детектор оценивается на 28) | пара по месту и времени (уровень A): снимок и полевой счёт совпадают по времени, месту и площади; не калибровочная пара |
| Видимый сигнал на снимке | **0** из 3 | видимый сигнал на снимке: в паре с предметами в поле и оцениваемым детектором есть срабатывания в полосе |
| Калибровочная пара «снимок → шт./км²» | **0** (нужно 4–12) | калибровочная пара «снимок → шт./км²»: пара по месту и времени с ненулевым сигналом снимка |

- **Пара по месту и времени** — снимок и полевой счёт совпадают по времени, месту и обследованной площади (ADIS, камера судна, > 5 см). Это не калибровочная пара.
- **Видимый сигнал на снимке.** На 6 синхронных отрезках ADIS с единичными предметами (3.5–4.4 шт./км²) детектор предметы не увидел: оценивается на 3 из 6 — на всех 0 пикселей. Это согласуется с физикой (доля покрытия ≈ 6.6·10⁻⁸, крупнейший предмет 0.7 % пикселя), но не задаёт общий предел для всех скоплений: плотные полосы мусора эти пары не проверяют.
- **Калибровочная пара «снимок → шт./км²»** — пара по месту и времени с ненулевым сигналом снимка. Их 0, поэтому перевода «снимок → шт./км²» нет.

Формула `C = N / A`; для полосы `A = L[км] × W[м] / 1000`; по профилю `C = ΣN / ΣA`. Интервал Гарвуда 95 % (только счётная ошибка): `N_lo = χ²(0.025; 2N)/2`, `N_hi = χ²(0.975; 2N+2)/2`, обе границы делим на A.

| профиль | событий | ΣN / ΣA | C [95 % Пуассон] | медиана событий [p25–p75] |
|---|---:|---|---|---|
| S2 Саргассы, визуально, пластик > 2 см (основной) | 63 | 697 / 12.94 км² | 53.9 [49.9–58.0] | 36.1 [20.5–76.4] |
| S1 GPGP, трал, пластик 5–50 см | 83 | N нет в источнике | — | 633.7 [346.5–955.7] |
| справка: S3 Сев. море, весь мусор | 41 | 199 / 5.86 км² | 34.0 [29.4–39.0] | 29.5 [16.8–34.2] |
| справка: S4 Чёрное море, весь мусор | 33 | N нет в источнике | — | 224.9 [102.4–356.6] |

- Профили не смешиваются; «весь мусор» (S3, S4) — не пластик.
- Оценка по полевым данным на карте — **медиана профиля**: на отложенном test модель не лучше медианы (S2 ridge_log 30.0 против медианы 25.2; S1 370.0 против 371.1). Подпись — «оценка по полевым данным, не по снимку».
- Изменчивость S2 в ln C: между событиями sd 0.84, из неё пуассоновская часть sd 0.43 (27 % дисперсии); между трансектами одних суток сверх Пуассона sd 0.46 — мелкомасштабная пятнистость.
- ADIS для сравнения: 21 444 отрезков по 10 км, 14 549 км²; нулевых отрезков 72 %; ΣN/ΣA = 1.55 шт./км² (> 5 см, без поправки на пропуски); предметов ≥ 20 м² — 23 (0.0016 на км²).

## 2. Снимок: площадь маски и доля покрытия, м²/км² (измерение по маске, не штуки)

Величина та же, что LWD у Cózar et al. 2024 (Nat. Commun. 15:4637): `S = пиксели маски на пригодной воде / пиксели пригодной воды · 10⁶` (м² на км²). Это **доля покрытия подозрительного материала**: пена, водоросли и суда не исключены, поэтому это не мусор и не шт./км². Ноль — «ниже порога срабатывания», а не «чисто».

- Живые сцены, текущий детектор (weights/lgbm без гармонизации): > 0 у 52 из 64; медиана 3.2, p90 39.6, максимум 82 м²/км²; по всем сценам 10.3.
- От выбора порога (все пороги, которые MARIDA val не отличает от рабочего) медиана меняется от 0.84 до 18.2 — в 9 раз (медиана отношения по сценам).
- Сцены пар CSV: в 11 принятых полосах сигнал 0.

## 3. Калибровка «доля покрытия → шт./км²» (нужна, сейчас невозможна)

Модель `ln C = ln k + b · ln S` (S — доля покрытия в том же следе и в то же время, что и полевой счёт). Для неё нужны калибровочные пары — пары по месту и времени с S > 0; их 0.

- Для множителя k в пределах ×/÷2 нужно 4–12 независимых калибровочных пар (в зависимости от шума спутника); чтобы обнаружить связь: r = 0,3 — 85 пар, r = 0,5 — 30, r = 0,7 — 14.
- Доля полос с сигналом сейчас ≤ 0.28 (95 %), значит обследований нужно в ≥ 3.5 раза больше, чем пар.
- Пол точности: пятнистость и Пуассон не дают интервалу одной оценки быть уже ×/÷3.5 даже при идеальном спутнике (у медианы профиля ×/÷5.1).
- Пары ADIS «0 на снимке при N шт./км²» годятся для проверки согласованности нуля и оценки ложных тревог, но не для регрессии: сигнал снимка в них нулевой.

## 4. Перевод площади в штуки — не используется

Перевод «площадь маски / размер предмета = штуки» при допущениях о заполнении пикселя и размере предметов даёт разброс в 3 125 раз (≈ 3,5 порядка), поэтому он нигде не показывается: перевод площади маски в штуки не показываем — нет калибровочных пар «снимок → шт./км²». Главный статус спутниковой зоны — «концентрация по снимку не подтверждена». Массу и физическую концентрацию не оцениваем.

## 5. Калибровка по ячейкам: аналогия и отрицательный результат

- Аналогия: пальмы на гектар по Sentinel-2 с опорой на подсчёт по снимкам высокого разрешения (arXiv 2105.11207): MAE ±7,3 пальмы/га. Там это возможно: там объект неподвижен, однороден и даёт устойчивый сигнал в пикселе, а опорный счёт совпадает со снимком.
- Для мусора: мусор дрейфует (часы между снимком и полем уже сдвигают поле), разнороден по размеру и материалу и занимает доли процента пикселя; поэтому калибровка по ячейкам требует независимой проверки — у нас она дала отрицательный результат.
- Результат (`reports/quantity/cell_calibration.md`, проверка записана до сравнения, стоп-правило < 20 независимых ячеек): калибровки по ячейкам нет: в одном периоде общих дат поле × спутник 0; климатологии разных лет ранжируют районы слабо (ρ ≈ география — удалённость от берега), правило принятия не пройдено. В одном периоде общих дат поле × спутник — 0; ячеек с сигналом нашего детектора — 1. Климатологии разных лет (не калибровка): ρ = 0.18 на 123 ячейках, 95 % ДИ по судо-суткам [-0.03; 0.38].
- **Попытка «спектр → доля покрытия» с отказом.** На PLP2019 (63 пикселей с измеренной долей пластика, 5 дат) ранговая связь с FDI ρ = 0.09, с NIR ρ = 0.14; модель по FDI на отложенной дате — MAE 8.5–16.5 п.п. против 7.6–16.6 у предсказания средним. Вывод: перевод «спектр пикселя → доля покрытия пластиком» не подтверждён: связь слабая, знак меняется по датам, модель по FDI на отложенной дате не лучше предсказания средним. Поэтому штук у спутниковой зоны не показываем.
