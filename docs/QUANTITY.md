# QUANTITY — оценка количества: поле и спутник раздельно (§11 п.5, L93)

Главное: **пар уровня A — 0**, поэтому подсчёта «снимок → шт./км²» нет. Ниже четыре отдельные величины. Их нельзя складывать или переводить одну в другую без калибровки.
Числа берутся из `reports/quantity/*.json` и `summary.md` (`scripts/case/quantity_report.py`; сцены — `scripts/case/quantity_live.py`). Код — `src/macroplastic/case/coverage.py` (+ `tests/test_case_coverage.py`) и `concentration.py`.

## 1. Полевая концентрация, шт./км² (измерение)
Формула: `C = N / A`. Для полосы `A = L[км] × W[м] / 1000`. По профилю считаем `C = ΣN / ΣA`.
Интервал Гарвуда 95 % (только счётная ошибка): `N_lo = χ²(0.025; 2N)/2`, `N_hi = χ²(0.975; 2N+2)/2`, обе границы делим на A.

|---|---:|---|---|---|---|---|
| S2 Саргассы, визуально, пластик > 2 см (основной) | 63 | 697 / 12.94 км² | 53.9 [49.9–58.0] | 36.1 [20.5–76.4] | 37.0 [9.0–175.2] | 25.2 / 30.0 (ridge_log) |
| S1 GPGP, трал, пластик 5–50 см | 83 | N нет | — | 633.7 [346.5–955.7] | 724.1 [74.4–2 634] | 371.1 / 370.0 (knn5_log) |
| справка: S3 Сев. море, весь мусор | 41 | 199 / 5.86 | 34.0 [29.4–39.0] | 29.5 | — | — |

Профили не смешиваются. На отложенном test модели не лучше медианы, поэтому на карте — медиана профиля.
Изменчивость S2 в ln C: между событиями sd 0.84; из неё пуассоновская часть sd 0.43 (27 % дисперсии). Между трансектами одних суток рейса остаётся sd 0.46 сверх Пуассона — это мелкомасштабная пятнистость.
Для сравнения, ADIS (L91; камера с судна, > 5 см; 21 444 отрезка по 10 км, 14 549 км², `reports/quantity/adis_field.json`): 72 % отрезков — ноль, ΣN/ΣA = 1.55 шт./км² без калибровки. Внутри суток разброса сверх Пуассона нет (sd 0.0), но счёт мал, поэтому σ Пуассона 0.75.
Доля площади предметов на отрезке: медиана 0, p99 16 м²/км², максимум 248 м²/км². Предметов ≥ 20 м², которые в одиночку закрывают ≥ 20 % пикселя, — 23 на 14 549 км² (0.0016 на км²). В полосе 0.8 км² ожидается 0.0013 такого предмета, то есть P(≥ 1) ≈ 0.13 %.

## 2. Спутниковая доля покрытия, м² на км² пригодной воды (измерение по снимку, не шт.)
Величина та же, что у Cózar A., Arias M., Suaria G. et al. (2024) *Proof of concept for a new sensor to monitor marine litter from space*, Nat. Commun. 15:4637, doi:10.1038/s41467-024-48674-7. У них это litter-windrow density:
`LWD = a_lw / a_o · 10⁶` (ppm = м²/км²). Здесь `a_lw` — площадь пикселей скопления (целые пиксели по 100 м²), `a_o` — наблюдённая вода без облаков и без ветра > 5 м/с.
Для сравнения, у Cózar: 288 166 снимков, 14 374 «окна», 94.5 км² (сверено с каталогом: 94.46 км²); среднее по Средиземному морю 0.2 ppm, горячие точки 9–56 ppm (сетка 0.25°, среднегодовое). Предел обнаружения — около 20 % покрытия пикселя. В число предметов они не переводят.
У нас: `S = пиксели маски на пригодной воде / пиксели пригодной воды · 10⁶`. Ноль означает «ниже предела обнаружения», а не «чисто». Предел — один пиксель (или минимальный объект) на этой площади.
Диапазон по порогу: берём все пороги, которые MARIDA val не отличает от рабочего (F1 ≥ max − 0.01, это 0.10–0.88). Правило задано до расчёта на сценах.

- **Сцены пар** (`data/pairs/quality`, 22 с картой вероятностей): в 11 принятых полосах 0 срабатываний. Один пиксель в полосе ≈ 124 м²/км² (медиана). Полевая C у этих событий 52–976 шт./км². Это не пары A: нет синхронности по дрейфу, у S4 неизвестно время.
- **Сцены подготовки** (`data/live`, 64 сцены, 18 регионов, вырезки ≈ 25×25 км; постобработка как в сервисе: компоненты ≥ 2 px, облачный буфер 5 px, без фильтра судов и кильватера). Таблица по регионам — в `reports/quantity/summary.md`.

## 3. Калибровка связи «доля покрытия → шт./км²» (нужна, сейчас невозможна)
Модель: `ln C_i = ln k + b · ln S_i + ε_i`. Здесь S_i — доля покрытия в том же следе и в то же время, что и трансекта; при b = 1 это пропорция `C = k·S`.
В ε входят несовпадение следа (sd 0.46), шум Пуассона (0.43) и ошибка спутниковой доли: порог, доля мусора в пикселе, пена и водоросли.
- Число пар, чтобы 95 % ДИ множителя k был в ×/÷ f: `n = ⌈(1.96·σ / ln f)²⌉`. При σ спутника 0.3 / 0.56 (измерено: разброс ×9 по порогу, σ = ln 9 / 3.92) / 1.0 для ×/÷2 нужно 4 / 6 / 12 пар, для ×/÷1.5 — 12 / 17 / 33.
- Обнаружить связь (α 0.05, мощность 0.8): при r 0.3 нужно 85 пар, при r 0.5 — 30, при r 0.7 — 14. SE наклона b при n = 30 — 0.16–0.26.
- Предел без спутника: пятнистость + Пуассон дают σ 0.64. Значит, даже при идеальном спутнике и бесконечном числе пар интервал одной оценки не уже **×/÷3.5** (у медианы профиля ×/÷5.1). Интервал ×/÷2 или ×/÷3 для одной сцены недостижим.
- Все эти числа — нижняя граница. Они предполагают, что S > 0 в каждой паре. Сейчас 0 из 11 полос с S > 0: доля ненулевых ≤ 0.28 (95 %), значит обследований нужно в ≥ 3.5 раза больше.
- Требования к паре A: |dt| ≤ ~4 ч (0.2 м/с, буфер 3 км); тот же след; та же совокупность (метод, размер, материал); одна пара на сутки или сцену (трансекты одних суток не независимы).
- Почему нельзя сейчас: пар A 0 (29 → 12 → 0 синхронных). Кроме того, обычная полевая плотность на 5–6 порядков ниже того, что видит пиксель (п. 4). Калибровать можно только на скоплениях (windrows), а судовые трансекты их почти не пересекают. Синхронная пара «0 на снимке при N шт./км²» (кандидаты ADIS, L91/L100) годится только для проверки согласованности нуля, не для регрессии. Проверка: при рассеянном мусоре ожидаемое число срабатываний ≈ λ·A, где λ = 0.0016 предмета ≥ 20 м² на км² (ADIS). Отрицательная пара A согласуется с этим, если на снимке 0. Срабатывание на отрезке без крупных предметов означает ложное срабатывание детектора (кандидат D).
- Первые пары A от L100 (`data/search/adis/candidates.csv`, на 26.09 01:30): 4 отрезка ADIS, |dt| 0.1–0.9 ч, по 1 предмету > 5 см на 0.50–0.56 км². Во всех 4 полосах (2.36 км² пригодной воды) 0 срабатываний, S = 0. Ожидалось λ·A = 0.0016 × 2.36 ≈ 0.004 срабатывания, так что результат согласуется с нулём. Для калибровки k эти пары ничего не дают: S = 0 цензурирован, N = 1.

## 4. Исследовательский сценарий «площадь / размер предмета = штуки» (НЕ основное число)
`N = S_маски · f / ā`. Здесь f — доля пикселя, занятая мусором: от 0.2 (порог обнаружения по Cózar) до 1.0. ā — средняя площадь предмета, это допущение.
Минимум `S·f_min/ā_max`, максимум `S·f_max/ā_min`. Дополнительно допускается: предметы не перекрываются, в маске только мусор.
- Размеры: в CSV есть только класс > 2 см. Поэтому ā по составу item_observation S2 (197 предметов; фрагменты 131, тара 15, прочее) берём с допущением о длинах типов: 0.0015–0.037 м². Для сравнения, по данным: ADIS (22 642 предмета, камера с судна) медиана 0.27 м², p25–p75 0.13–0.62; Lebreton 2018 (аэро, 1 594) медиана 0.19 м².
- Минимальный объект (200 м²): по составу S2 — 1 085–130 000 предметов; по границам класса 2–50 см — 160–500 000 (разброс ×3 125); по размерам ADIS (p25–p75 0.13–0.62 м²) — 65–1 527; по размерам Lebreton (0.11–0.35 м²) — 114–1 894.
- Медианное «окно» Cózar (3 700 м²): по составу S2 — 20 000–2.5 млн, по размерам ADIS — 1 200–28 000 предметов.
- Обратный расчёт: полевая медиана 37 шт./км² — это 0.055–1.4 м² мусора на км². Чтобы пиксель сработал, локально нужно 5·10⁶–1.3·10⁸ шт./км², в 10⁵–10⁶ раз больше медианы поля.
Вывод: такой пересчёт даёт разброс на 2–3 порядка и держится только на допущениях. На карту как число он не идёт.
