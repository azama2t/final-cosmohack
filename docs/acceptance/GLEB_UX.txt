Заметки Глеба по интерфейсу для эколога (26.09, 17:29), сокращённо. Исходник для §47.
Путь эксперта: выбрать акваторию и даты → открыть снимок → изучить зону и качество → понять итоговый статус → выгрузить результат.
Проблемы: (1) после выбора акватории непонятно, как выбрать и листать даты; пустой результат не объяснён;
(2) повторные клики по зоне/маркеру ведут то к снимку, то к карточке, то в «Студию» — одно действие = один результат, явный «назад»;
(3) «Кейс» не объясняет назначения — переименовать/пояснить; (4) дрейф спрятан — дать понятным доп. действием у подходящей зоны,
только на реальных метеоданных/течениях с источником, временем, допущениями и неопределённостью; нет расчёта — не имитировать;
(5) разнести функции по уровням: основной сценарий / подробный анализ / качество / полевые данные / дрейф / экспорт; шум с главного экрана убрать, не удаляя;
(6) кнопка «Демо»: реальный пример в 5 шагов сцена → зона → качество → итоговый статус → экспорт; после демо легко начать свой поиск;
(7) карточка спутниковой зоны сразу: «Есть детекция плавающего материала. Пластик и количество шт./км² по этому снимку не подтверждены. Принятых полевых пар: 0.»;
(8) карточка полевого наблюдения: плотность, исходное N, площадь A, расчёт N / A = шт./км², профиль, источник; нет N — не восстанавливать из округлённой плотности; ориентиры профиля — в подробности;
(9) на главном экране один главный ответ и одно следующее действие; спутник, поле и эксперимент различимы; без принятой пары не изображать прямое сопоставление.
