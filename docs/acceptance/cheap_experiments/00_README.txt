ДЕШЁВЫЕ ЭКСПЕРИМЕНТЫ ДЛЯ ДЕТЕКТОРА МАКРОПЛАСТИКА

Контекст текущего проекта, который нельзя игнорировать:
- текущая финальная модель: weights/lgbm;
- порог: P >= 0.63, выбран по MARIDA val;
- модель уже использует 11 каналов Sentinel-2 + 8 спектральных индексов;
- затем были добавлены 29 оконных признаков;
- текущий MARIDA test F1 = 0.871, P = 0.824, R = 0.924;
- MARIDA test уже был открыт один раз и НЕ должен использоваться для выбора новых настроек;
- текущая проблема — перенос на реальные L2A-сцены: суда, пена/барашки, блик, мелкие облака;
- detector_v2 с дополнительными B/D данными уже проверялся: 13 вариантов x 3 seed, ни один не прошёл заранее заданное правило принятия;
- гармонизация отключена; production-режим — harmonize=none.

Порядок:
1. 01_feature_ablation.txt — самый дешёвый эксперимент. Обучение только небольших LightGBM на уже готовых признаках, без скачивания снимков и без изменения production.
2. 02_pretrained_unetpp_benchmark.txt — zero-training benchmark готового MarineDebrisDetector/U-Net++ на тех же независимых наборах. Цель: проверить, помогает ли spatial context.
3. 03_lgbm_unetpp_ensemble.txt — выполнять ТОЛЬКО если эксперимент 2 показывает комплементарность. Это дешёвый score-level/post-filter ensemble без обучения большой сети.

Общее правило для всех экспериментов:
- ничего не заменять в production автоматически;
- weights/lgbm не перезаписывать;
- final test не использовать для выбора признаков, порогов, весов или правил;
- все новые артефакты писать в новый каталог reports/cheap_experiments/...;
- сохранить команды запуска, seed, версии библиотек и CSV/JSON с результатами;
- отрицательный результат тоже является результатом: не подгонять эксперимент до победы.
