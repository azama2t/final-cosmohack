# presentation/screens_final — набор скринов сервиса (L161, §65 п.Б)

14 шагов сценария §65 п.А + мобильный вид. У каждого кадра есть версия с подписью-субтитром внизу
(`NN_имя.png`) и без подписи (`NN_имя_clean.png`, для деки/README). Подписи честные: зона — это
не число штук мусора, дрон — не спутник, NASA — ежедневный обзор Земли (не детекция), PRIME — демо-режим.

| Файл | Что показано | Источник данных |
|---|---|---|
| `01_earth_sources.png` (+ `_clean`) | Земля и источники: 4 независимых переключателя данных (архив S2 / свежие S2 / поле / дроны) | живой сервис :8070, стартовый список снимков |
| `02_region_dates.png` (+ `_clean`) | Выбор района и дат на карте и таймлайне | живой сервис, таймлайн снимков |
| `03_scene_zones.png` (+ `_clean`) | Снимок Sentinel-2 с нумерованными зонами по кадру | снимок Sentinel-2, зоны по модели |
| `04_zone_card.png` (+ `_clean`) | Карточка зоны: статус, «оценка количества» — по снимку не определено / по полю — независимая оценка / по фото | карточка зоны (снимок + при наличии полевые/фото данные) |
| `05_quality.png` (+ `_clean`) | Проверка качества: примеры верных срабатываний, пропусков и ложных на сложном фоне | метрики модели на разметке |
| `06_studio.png` (+ `_clean`) | Студия — детальный просмотр снимка зоны | снимок Sentinel-2 |
| `07_export.png` (+ `_clean`) | Выгрузка результатов в CSV / GeoJSON | выгрузка по открытой зоне |
| `08_realtime.png` (+ `_clean`) | Реальное время: свежий Sentinel-2, обработан моделью автоматически — «не проверено человеком» | воронка обработки свежих сцен (API /api/v3/fresh_s2) |
| `09_drones.png` (+ `_clean`) | Дроны и фото: кадр с рамками — наш счётчик отдельно от разметки (не одно и то же число) | набор фото/видео с дрона, разметка + предсказание модели |
| `12_nasa.png` (+ `_clean`) | NASA — ежедневный обзор снимков Земли (не детекция мусора) | NASA GIBS (VIIRS/MODIS) через прокси сервиса |
| `13_prime.png` (+ `_clean`) | PRIME — демонстрационный режим по просьбе жюри (плашка «ДЕМО» видна) | синтетические демо-данные, не реальные измерения |
| `14_field.png` (+ `_clean`) | Полевые измерения — данные организаторов (CSV, судно) | полевые измерения организаторов |
| `m1_earth_sources_mobile.png` (+ `_clean`) | Мобильный вид: Земля и источники | живой сервис, мобильный вид |
| `m3_drones_mobile.png` (+ `_clean`) | Мобильный вид: дроны и фото | набор дронов, мобильный вид |
